# Task 3: IsPalindrome

## Паттерн: С двух сторон

**Зелёные флаги:** строка, сравнение символов с концов, сужение к центру

## Условие

Дана строка s из строчных латинских букв. Проверь, является ли она палиндромом (читается одинаково слева направо и справа налево).

## Решение

```typescript
export function isPalindrome(s: string): boolean {
    let left = 0;
    let right = s.length - 1;

    while (left < right) {
        if (s[left] !== s[right]) {
            return false;
        }
        left++;
        right--;
    }

    return true;
}
```

## Разбор

**Идея:** Сравниваем символы с двух концов. Как только нашли несовпадение — это не палиндром. Дошли до центра — палиндром.

**Пошагово на примере `"racecar"`:**

| Шаг | L | R | s[L] | s[R] | Совпадают? |
|-----|---|----|-----|------|-----------|
| 0 | 0 | 6 | r | r | ✅ |
| 1 | 1 | 5 | a | a | ✅ |
| 2 | 2 | 4 | c | c | ✅ |
| 3 | 3 | 3 | e | e | ✅ (L === R, выход) |

Все символы совпали → true.

**Сложность:** O(n) по времени, O(1) по памяти.
