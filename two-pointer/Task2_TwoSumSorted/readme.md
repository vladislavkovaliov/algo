# Task 2: TwoSumSorted

## Паттерн: С двух сторон

**Зелёные флаги:** отсортированный массив, найти пару по сумме

## Условие

Дан массив чисел, отсортированный по возрастанию, и число target. Найди два числа, которые в сумме дают target. Верни их индексы.

## Решение

```typescript
export function twoSumSorted(numbers: number[], target: number): number[] {
    let left = 0;
    let right = numbers.length - 1;

    while (left < right) {
        const sum = numbers[left] + numbers[right];

        if (sum === target) {
            return [left, right];
        } else if (sum < target) {
            left++;
        } else {
            right--;
        }
    }

    return [-1, -1];
}
```

## Разбор

**Идея:** Ставим указатели на два конца массива. Сумма больше target → двигаем правый (уменьшаем сумму). Сумма меньше target → двигаем левый (увеличиваем сумму).

**Пошагово на примере `[2, 7, 11, 15]`, target = 9:**

| Шаг | L | R | nums[L] + nums[R] | Сравнение | Действие |
|-----|---|----|-------------------|----------|----------|
| 0 | 0 | 3 | 2 + 15 = 17 | 17 > 9 | R → 2 |
| 1 | 0 | 2 | 2 + 11 = 13 | 13 > 9 | R → 1 |
| 2 | 0 | 1 | 2 + 7 = 9 | 9 = 9 | **Ответ: [0, 1]** |

**Сложность:** O(n) по времени, O(1) по памяти.
