# Task 15: ArrayIntersectionSorted

## Паттерн: Каждому по указателю

**Зелёные флаги:** два массива, общие элементы, с учётом повторов

## Условие

Даны два массива чисел nums1 и nums2, отсортированных по возрастанию. Найди пересечение массивов с учётом повторений. Если число встречается 3 раза в nums1 и 2 раза в nums2, то в ответе оно должно быть 2 раза.

## Решение

```typescript
export function arrayIntersectionSorted(nums1: number[], nums2: number[]): number[] {
    const result: number[] = [];
    let i = 0;
    let j = 0;

    while (i < nums1.length && j < nums2.length) {
        if (nums1[i] < nums2[j]) {
            i++;
        } else if (nums1[i] > nums2[j]) {
            j++;
        } else {
            result.push(nums1[i]);
            i++;
            j++;
        }
    }

    return result;
}
```

## Разбор

**Идея:** Как обычное пересечение, но без проверки на дубликаты в ответе — каждое совпадение добавляем.

**Пошагово на примере `[1, 1, 2, 2]` + `[2, 2]`:**

| Шаг | i | j | nums1[i] | nums2[j] | Действие | Результат |
|-----|---|----|---------|---------|----------|-----------|
| 0 | 0 | 0 | 1 | 2 | 1<2 → i++ | `[]` |
| 1 | 1 | 0 | 1 | 2 | 1<2 → i++ | `[]` |
| 2 | 2 | 0 | 2 | 2 | равны → push(2), i++, j++ | `[2]` |
| 3 | 3 | 1 | 2 | 2 | равны → push(2), i++ | `[2, 2]` |

Ответ: `[2, 2]`.

**Сложность:** O(n + m) по времени, O(1) доп. памяти.
