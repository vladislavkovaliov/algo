# Task 13: IsSubsequence

## Паттерн: Каждому по указателю

**Зелёные флаги:** две строки, проверить вхождение по порядку

## Условие

Даны две строки s и t. Проверь, является ли s подпоследовательностью t. То есть можно ли получить s, удалив некоторые символы из t (не меняя порядок оставшихся).

## Решение

```typescript
export function isSubsequence(s: string, t: string): boolean {
    let si = 0;
    let ti = 0;

    while (si < s.length && ti < t.length) {
        if (s[si] === t[ti]) {
            si++;
        }
        ti++;
    }

    return si === s.length;
}
```

## Разбор

**Идея:** si — указатель по s, ti — по t. Ищем каждый символ s в t по порядку. Если нашли — двигаем si. ti двигается всегда.

**Пошагово на примере s = `"ace"`, t = `"abcde"`:**

| Шаг | si | ti | s[si] | t[ti] | Совпали? | Действие |
|-----|---|----|-------|-------|----------|----------|
| 0 | 0 | 0 | a | a | ✅ | si→1 |
| 1 | 1 | 1 | c | b | ❌ | — |
| 2 | 1 | 2 | c | c | ✅ | si→2 |
| 3 | 2 | 3 | e | d | ❌ | — |
| 4 | 2 | 4 | e | e | ✅ | si→3 |

si = 3 = s.length → true.

**Сложность:** O(len(t)) по времени, O(1) по памяти.
