# Task 9: SortArrayByParity

## Паттерн: Быстрый и медленный

**Зелёные флаги:** in-place, переставить по условию (чётные → нечётные)

## Условие

Дан массив чисел nums. Переставь элементы так, чтобы сначала шли все чётные числа, а потом все нечётные. Порядок внутри групп не важен. Изменяй массив in-place. Верни изменённый массив.

## Решение

```typescript
export function sortArrayByParity(nums: number[]): number[] {
    let slow = 0;

    for (let fast = 0; fast < nums.length; fast++) {
        if (nums[fast] % 2 === 0) {
            [nums[slow], nums[fast]] = [nums[fast], nums[slow]];
            slow++;
        }
    }

    return nums;
}
```

## Разбор

**Идея:** slow — граница чётных. fast ищет чётные. Когда находит — меняет с элементом на границе.

**Пошагово на примере `[3, 1, 2, 4]`:**

| Шаг | slow | fast | nums[fast] | Чёт? | Действие | Массив |
|-----|------|------|-----------|------|----------|--------|
| 0 | 0 | 0 | 3 | нет | — | `[3, 1, 2, 4]` |
| 1 | 0 | 1 | 1 | нет | — | `[3, 1, 2, 4]` |
| 2 | 0 | 2 | 2 | да | swap, slow=1 | `[2, 1, 3, 4]` |
| 3 | 1 | 3 | 4 | да | swap, slow=2 | `[2, 4, 3, 1]` |

Ответ: `[2, 4, 3, 1]`.

**Сложность:** O(n) по времени, O(1) по памяти.
