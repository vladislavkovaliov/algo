# Task 12: IntersectionOfTwoArrays

## Паттерн: Каждому по указателю

**Зелёные флаги:** два массива, найти общие элементы

## Условие

Даны два массива чисел nums1 и nums2, отсортированных по возрастанию. Найди все числа, которые встречаются в обоих массивах (без повторов в ответе). Верни массив.

## Решение

```typescript
export function intersectionOfTwoArrays(nums1: number[], nums2: number[]): number[] {
    const result: number[] = [];
    let i = 0;
    let j = 0;

    while (i < nums1.length && j < nums2.length) {
        if (nums1[i] < nums2[j]) {
            i++;
        } else if (nums1[i] > nums2[j]) {
            j++;
        } else {
            if (result.length === 0 || result[result.length - 1] !== nums1[i]) {
                result.push(nums1[i]);
            }
            i++;
            j++;
        }
    }

    return result;
}
```

## Разбор

**Идея:** Двигаем указатели: если элемент слева меньше — двигаем левый; если справа меньше — двигаем правый; если равны — добавляем в ответ (проверив, что не дубликат).

**Пошагово на примере `[1, 1, 2, 2]` + `[2, 2]`:**

| Шаг | i | j | nums1[i] | nums2[j] | Действие | Результат |
|-----|---|----|---------|---------|----------|-----------|
| 0 | 0 | 0 | 1 | 2 | 1<2 → i++ | `[]` |
| 1 | 1 | 0 | 1 | 2 | 1<2 → i++ | `[]` |
| 2 | 2 | 0 | 2 | 2 | равны → push(2), i++, j++ | `[2]` |
| 3 | 3 | 1 | 2 | 2 | i≥длины → конец | `[2]` |

Ответ: `[2]`.

**Сложность:** O(n + m) по времени, O(1) доп. памяти.
