# Task 7: MoveZeroes

## Паттерн: Быстрый и медленный

**Зелёные флаги:** in-place, сохранить порядок ненулевых элементов

## Условие

Дан массив чисел nums. Перемести все нули в конец массива, сохраняя порядок остальных элементов. Изменяй массив in-place. Верни изменённый массив.

## Решение

```typescript
export function moveZeroes(nums: number[]): number[] {
    let slow = 0;

    for (let fast = 0; fast < nums.length; fast++) {
        if (nums[fast] !== 0) {
            [nums[slow], nums[fast]] = [nums[fast], nums[slow]];
            slow++;
        }
    }

    return nums;
}
```

## Разбор

**Идея:** slow указывает на позицию для следующего ненулевого элемента. fast ищет ненулевые. Когда fast находит ненулевой — меняем его с элементом на slow.

**Пошагово на примере `[0, 1, 0, 3, 12]`:**

| Шаг | slow | fast | nums[fast] | Действие | Массив |
|-----|------|------|-----------|----------|--------|
| 0 | 0 | 0 | 0 | ноль → пропуск | `[0, 1, 0, 3, 12]` |
| 1 | 0 | 1 | 1 | swap slow↔fast, slow=1 | `[1, 0, 0, 3, 12]` |
| 2 | 1 | 2 | 0 | ноль → пропуск | `[1, 0, 0, 3, 12]` |
| 3 | 1 | 3 | 3 | swap slow↔fast, slow=2 | `[1, 3, 0, 0, 12]` |
| 4 | 2 | 4 | 12 | swap slow↔fast, slow=3 | `[1, 3, 12, 0, 0]` |

Ответ: `[1, 3, 12, 0, 0]`.

**Сложность:** O(n) по времени, O(1) по памяти.
