# Task 10: RemoveDuplicatesFromSortedArray2

## Паттерн: Быстрый и медленный (вариация)

**Зелёные флаги:** in-place, отсортировано, разрешить не больше 2 повторов

## Условие

Дан отсортированный массив чисел. Удали дубликаты in-place так, чтобы каждое число встречалось не более двух раз. Верни длину изменённого массива.

## Решение

```typescript
export function removeDuplicates2(nums: number[]): number {
    if (nums.length <= 2) return nums.length;

    let slow = 2;

    for (let fast = 2; fast < nums.length; fast++) {
        if (nums[fast] !== nums[slow - 2]) {
            nums[slow] = nums[fast];
            slow++;
        }
    }

    return slow;
}
```

## Разбор

**Идея:** slow — позиция для вставки, fast проходит по массиву. Сравниваем nums[fast] с nums[slow - 2] — если они разные, значит мы уже встретили меньше 2 повторов этого числа.

**Пошагово на примере `[1, 1, 1, 2, 2, 3]`:**

| Шаг | slow | fast | nums[fast] | nums[slow-2] | Действие | Массив |
|-----|------|------|-----------|-------------|----------|--------|
| 0-1 | 2 | 2 | 1 | nums[0]=1 | равны → пропуск | `[1, 1, 1, 2, 2, 3]` |
| 2 | 2 | 3 | 2 | nums[0]=1 | разные → nums[2]=2, slow=3 | `[1, 1, 2, 2, 2, 3]` |
| 3 | 3 | 4 | 2 | nums[1]=1 | разные → nums[3]=2, slow=4 | `[1, 1, 2, 2, 2, 3]` |
| 4 | 4 | 5 | 3 | nums[2]=2 | разные → nums[4]=3, slow=5 | `[1, 1, 2, 2, 3, 3]` |

Ответ: 5. Первые 5 элементов `[1, 1, 2, 2, 3]`.

**Сложность:** O(n) по времени, O(1) по памяти.
