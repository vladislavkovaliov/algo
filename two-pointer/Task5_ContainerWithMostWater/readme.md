# Task 5: ContainerWithMostWater

## Паттерн: С двух сторон

**Зелёные флаги:** массив высот, сужение области, площадь

## Условие

Дан массив высот height. Каждое число — высота вертикальной линии. Найди две линии, которые вместе с осью X образуют контейнер, вмещающий максимальное количество воды. Верни максимальную площадь.

## Решение

```typescript
export function containerWithMostWater(height: number[]): number {
    let left = 0;
    let right = height.length - 1;
    let maxArea = 0;

    while (left < right) {
        const area = Math.min(height[left], height[right]) * (right - left);
        maxArea = Math.max(maxArea, area);

        if (height[left] < height[right]) {
            left++;
        } else {
            right--;
        }
    }

    return maxArea;
}
```

## Разбор

**Идея:** Площадь контейнера = расстояние между линиями × min(высота левой, высота правой). Двигаем тот указатель, где высота меньше — так мы не теряем потенциально больший контейнер.

**Пошагово на примере `[1, 8, 6, 2, 5, 4, 8, 3, 7]`:**

| Шаг | L | R | Высоты | Расст. | Площадь | maxArea | Движем |
|-----|---|----|--------|--------|---------|---------|--------|
| 0 | 0 | 8 | 1, 7 | 8 | 1×8=8 | 8 | L (1<7) |
| 1 | 1 | 8 | 8, 7 | 7 | 7×7=49 | 49 | R (7<8) |
| 2 | 1 | 7 | 8, 3 | 6 | 3×6=18 | 49 | R (3<8) |
| 3 | 1 | 6 | 8, 8 | 5 | 8×5=40 | 49 | R (равно) |
| 4 | 1 | 5 | 8, 4 | 4 | 4×4=16 | 49 | R |
| … | → | → | … | | | 49 | |

Максимум = 49.

**Сложность:** O(n) по времени, O(1) по памяти.
