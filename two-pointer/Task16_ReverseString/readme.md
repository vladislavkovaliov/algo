# Task 16: ReverseString

## Условие

Дан массив символов s (строка в виде массива). Разверни его in-place (не создавая новый массив). Верни развёрнутый массив.

## Решение

```typescript
export function reverseString(s: string[]): string[] {
    let left = 0;
    let right = s.length - 1;

    while (left < right) {
        [s[left], s[right]] = [s[right], s[left]];
        left++;
        right--;
    }

    return s;
}
```

## Разбор

**Идея:** Два указателя с концов массива меняются местами и сходятся к центру.

**Пошагово на примере `["h", "e", "l", "l", "o"]`:**

| Шаг | L | R | Меняем | Массив |
|-----|---|----|--------|--------|
| 0 | 0 | 4 | h ↔ o | `["o", "e", "l", "l", "h"]` |
| 1 | 1 | 3 | e ↔ l | `["o", "l", "l", "e", "h"]` |
| 2 | 2 | 2 | — (L≥R) | `["o", "l", "l", "e", "h"]` |

Ответ: `["o", "l", "l", "e", "h"]`.

**Сложность:** O(n) по времени, O(1) по памяти.
