# Task 6: ThreeSumSorted

## Паттерн: С двух сторон (вариация — фиксируем первый элемент)

**Зелёные флаги:** отсортированный массив, найти тройки по сумме

## Условие

Дан массив чисел nums, отсортированный по возрастанию (все элементы уникальны), и число target. Найди все уникальные тройки чисел, которые в сумме дают target. Верни массив троек, каждая тройка отсортирована по возрастанию.

## Решение

```typescript
export function threeSumSorted(nums: number[], target: number): number[][] {
    const triplets: number[][] = [];

    for (let i = 0; i < nums.length - 2; i++) {
        if (i > 0 && nums[i] === nums[i - 1]) continue;

        let left = i + 1;
        let right = nums.length - 1;

        while (left < right) {
            const sum = nums[i] + nums[left] + nums[right];

            if (sum === target) {
                triplets.push([nums[i], nums[left], nums[right]]);

                while (left < right && nums[left] === nums[left + 1]) left++;
                while (left < right && nums[right] === nums[right - 1]) right--;

                left++;
                right--;
            } else if (sum < target) {
                left++;
            } else {
                right--;
            }
        }
    }

    return triplets;
}
```

## Визуализация движения указателей

**Пример:** `nums = [1, 2, 3, 4, 5, 6]`, `target = 9`

```
i=0 (nums[0]=1)

  i  L            R
  ↓  ↓            ↓
 [1, 2, 3, 4, 5, 6]    1+2+6=9  ✅ [1,2,6]
  ── ←────→ ──
  i     L       R
  ↓     ↓       ↓
 [1, 2, 3, 4, 5, 6]    1+3+5=9  ✅ [1,3,5]
  ── ── ←─→ ──
  i        L  R
  ↓        ↓  ↓
 [1, 2, 3, 4, 5, 6]    1+4+5=10 >9 → R--
  ── ── ── ──
  i        L
  ↓        ↓
 [1, 2, 3, 4, 5, 6]    L≥R → конец i=0
```

```
i=1 (nums[1]=2)

     i  L           R
     ↓  ↓           ↓
 [1, 2, 3, 4, 5, 6]    2+3+6=11 >9 → R--
     ── ── ── ──
     i  L        R
     ↓  ↓        ↓
 [1, 2, 3, 4, 5, 6]    2+3+5=10 >9 → R--
     ── ── ──
     i  L     R
     ↓  ↓     ↓
 [1, 2, 3, 4, 5, 6]    2+3+4=9  ✅ [2,3,4]
```

**Пошагово в таблице:**

| i | i_val | L | R | Сумма | Результат |
|---|-------|---|----|-------|-----------|
| 0 | 1 | 1 | 5 | 1+2+6=9 | **✅ [1,2,6]**, L→2, R→4 |
| 0 | 1 | 2 | 4 | 1+3+5=9 | **✅ [1,3,5]**, L→3 |
| 0 | 1 | 3 | 4 | 1+4+5=10 >9 | R→3 |
| 0 | 1 | 3 | 3 | L≥R → конец i=0 |
| 1 | 2 | 2 | 5 | 2+3+6=11 >9 | R→4 |
| 1 | 2 | 2 | 4 | 2+3+5=10 >9 | R→3 |
| 1 | 2 | 2 | 3 | 2+3+4=9 | **✅ [2,3,4]** |

Ответ: `[[1,2,6], [1,3,5], [2,3,4]]`.

## Пример с дубликатами

**Как работают while-циклы пропуска дубликатов**

`nums = [1, 2, 2, 3, 4, 4, 5, 6]`, `target = 9`

```
i=0 (nums[0]=1)

  i  L                  R
  ↓  ↓                  ↓
 [1, 2, 2, 3, 4, 4, 5, 6]    1+2+6=9  ✅ [1,2,6]
  ── ←───→
      skip dup: 2 == 2 → L прыгает с 1 на 2
      nums[left]=2 vs nums[left+1]=2 → left++

  i     L             R
  ↓     ↓             ↓
 [1, 2, 2, 3, 4, 4, 5, 6]    1+3+5=9  ✅ [1,3,5]
  ── ── ── ── ──
  i        L       R
  ↓        ↓       ↓
 [1, 2, 2, 3, 4, 4, 5, 6]    1+4+4=9  ✅ [1,4,4]
  ── ── ── ── ←───────→
                     skip dup: оба 4
                     nums[left]=4 vs nums[left+1]=4 → left++ (4→5)
                     nums[right]=4 vs nums[right-1]=4 → right-- (5→4)
                     left=5, right=4 → L≥R → конец i=0
```

```
i=1 (nums[1]=2)

     i  L             R
     ↓  ↓             ↓
 [1, 2, 2, 3, 4, 4, 5, 6]    2+2+6=10 >9 → R--
     ── ── ── ── ──
     i  L          R
     ↓  ↓          ↓
 [1, 2, 2, 3, 4, 4, 5, 6]    2+2+5=9  ✅ [2,2,5]
     ── ── ── ──
     i     L       R
     ↓     ↓       ↓
 [1, 2, 2, 3, 4, 4, 5, 6]    2+3+4=9  ✅ [2,3,4]
```

Без while-циклов после `[1,2,6]` left перешёл бы на позицию 2 (всё ещё `2`), и мы получили бы ещё один `[1,2,6]` — дубликат в ответе.

**Сложность:** O(n²) по времени, O(1) по памяти (без учёта ответа).
