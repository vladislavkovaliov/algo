# Task 14: FindDifference

## Паттерн: Каждому по указателю

**Зелёные флаги:** два массива, найти элементы которые есть в одном но нет в другом

## Условие

Даны два массива nums1 и nums2, отсортированных по возрастанию. Найди все числа, которые есть в nums1, но отсутствуют в nums2. Верни массив (отсортированный, без повторов).

## Решение

```typescript
export function findDifference(nums1: number[], nums2: number[]): number[] {
    const result: number[] = [];
    let i = 0;
    let j = 0;

    while (i < nums1.length) {
        if (j >= nums2.length || nums1[i] < nums2[j]) {
            if (result.length === 0 || result[result.length - 1] !== nums1[i]) {
                result.push(nums1[i]);
            }
            i++;
        } else if (nums1[i] > nums2[j]) {
            j++;
        } else {
            const val = nums1[i];
            while (i < nums1.length && nums1[i] === val) i++;
            while (j < nums2.length && nums2[j] === val) j++;
        }
    }

    return result;
}
```

## Разбор

**Идея:** nums1[i] < nums2[j] → элемент есть в первом, но ещё не достигли во втором → точно отсутствует. nums1[i] > nums2[j] → двигаем j. Равны → пропускаем все повторы этого числа в обоих массивах.

**Пошагово на примере `[1, 2, 3, 4]` + `[2, 4, 6]`:**

| Шаг | i | j | nums1[i] | nums2[j] | Действие | Результат |
|-----|---|----|---------|---------|----------|-----------|
| 0 | 0 | 0 | 1 | 2 | 1<2 → push(1), i++ | `[1]` |
| 1 | 1 | 0 | 2 | 2 | равны → i++, j++ | `[1]` |
| 2 | 2 | 1 | 3 | 4 | 3<4 → push(3), i++ | `[1, 3]` |
| 3 | 3 | 1 | 4 | 4 | равны → i++ | `[1, 3]` |

Ответ: `[1, 3]`.

**Сложность:** O(n + m) по времени, O(1) доп. памяти.
