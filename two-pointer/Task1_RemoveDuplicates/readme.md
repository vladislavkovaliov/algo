# Task 1: RemoveDuplicates

## Паттерн: Быстрый и медленный

**Зелёные флаги:** in-place, сохранить порядок, удалить дубликаты, массив отсортирован

## Условие

Дан массив чисел, отсортированный по возрастанию. Удали дубликаты in-place, чтобы каждое число встречалось только один раз. Верни длину изменённого массива.

## Решение

```typescript
export function removeDuplicates(nums: number[]): number {
    if (nums.length === 0) return 0;

    let slow = 0;

    for (let fast = 1; fast < nums.length; fast++) {
        if (nums[fast] !== nums[slow]) {
            slow++;
            nums[slow] = nums[fast];
        }
    }

    return slow + 1;
}
```

## Разбор

**Идея:** slow указывает на последний уникальный элемент, fast ищет следующий уникальный. Когда fast находит новый элемент — slow двигается вперёд и копирует значение.

**Пошагово на примере `[1, 1, 2]`:**

| Шаг | slow | fast | nums[slow] | nums[fast] | Действие | Массив |
|-----|------|------|-----------|-----------|----------|--------|
| 0 | 0 | 1 | 1 | 1 | равны → пропускаем | `[1, 1, 2]` |
| 1 | 0 | 2 | 1 | 2 | разные → slow=1, nums[1]=2 | `[1, 2, 2]` |

Конец. Возвращаем `slow + 1 = 2`. Первые 2 элемента `[1, 2]` — ответ.

**Сложность:** O(n) по времени, O(1) по памяти.
