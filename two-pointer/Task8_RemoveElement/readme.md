# Task 8: RemoveElement

## Паттерн: Быстрый и медленный

**Зелёные флаги:** in-place, удалить все вхождения, сохранить порядок

## Условие

Дан массив чисел nums и число val. Удали все вхождения val in-place, сохраняя порядок остальных элементов. Верни длину массива после удаления.

## Решение

```typescript
export function removeElement(nums: number[], val: number): number {
    let slow = 0;

    for (let fast = 0; fast < nums.length; fast++) {
        if (nums[fast] !== val) {
            nums[slow] = nums[fast];
            slow++;
        }
    }

    return slow;
}
```

## Разбор

**Идея:** slow — позиция для следующего элемента, не равного val. fast ищет такие элементы. Когда находит — копирует на slow.

**Пошагово на примере `[3, 2, 2, 3]`, val = 3:**

| Шаг | slow | fast | nums[fast] | ≠3? | Действие | Массив |
|-----|------|------|-----------|-----|----------|--------|
| 0 | 0 | 0 | 3 | нет | — | `[3, 2, 2, 3]` |
| 1 | 0 | 1 | 2 | да | nums[0]=2, slow=1 | `[2, 2, 2, 3]` |
| 2 | 1 | 2 | 2 | да | nums[1]=2, slow=2 | `[2, 2, 2, 3]` |
| 3 | 2 | 3 | 3 | нет | — | `[2, 2, 2, 3]` |

Ответ: 2. Первые 2 элемента `[2, 2]`.

**Сложность:** O(n) по времени, O(1) по памяти.
