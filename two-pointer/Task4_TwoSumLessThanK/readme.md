# Task 4: TwoSumLessThanK

## Паттерн: С двух сторон

**Зелёные флаги:** отсортированный массив, найти пару по сумме с ограничением

## Условие

Дан массив чисел, отсортированный по возрастанию, и число K. Найди максимальную сумму двух различных элементов, которая строго меньше K. Если такой пары нет, верни -1.

## Решение

```typescript
export function twoSumLessThanK(nums: number[], k: number): number {
    let left = 0;
    let right = nums.length - 1;
    let best = -1;

    while (left < right) {
        const sum = nums[left] + nums[right];

        if (sum < k) {
            best = Math.max(best, sum);
            left++;
        } else {
            right--;
        }
    }

    return best;
}
```

## Разбор

**Идея:** Как в TwoSumSorted, но вместо точного равенства мы запоминаем лучшую сумму меньше K. Если сумма < K — обновляем best и двигаем левый (пробуем увеличить). Если ≥ K — двигаем правый (уменьшаем).

**Пошагово на примере `[2, 3, 4, 5]`, K = 10:**

| Шаг | L | R | Сумма | < K? | best | Действие |
|-----|---|----|-------|------|-----|----------|
| 0 | 0 | 3 | 2+5=7 | ✅ | 7 | L→1 |
| 1 | 1 | 3 | 3+5=8 | ✅ | 8 | L→2 |
| 2 | 2 | 3 | 4+5=9 | ✅ | 9 | L→3 |
| 3 | 3 | 3 | — | — | — | L≥R → конец |

Ответ: 9.

**Сложность:** O(n) по времени, O(1) по памяти.
