# Task11: Tribonacci

## Паттерн: Одномерная ДП

**Зелёные флаги:** последовательность, три предыдущих значения, Tribonacci

## Условие

Дано число n. Верни n-е число Трибоначчи, где T(0)=0, T(1)=0, T(2)=1, T(n)=T(n-1)+T(n-2)+T(n-3).

---

**Постановка:** n-е число трибоначчи
**Формула:** dp[i] = dp[i-1] + dp[i-2] + dp[i-3]
**Что такое dp[i]?** i-е число Трибоначчи
**Почему именно такой переход?** классическое определение трибоначчи: сумма трёх предыдущих
**Пошагово на примере n=8:** dp[0]=0, dp[1]=0, dp[2]=1, dp[3]=1, dp[4]=2, dp[5]=4, dp[6]=7, dp[7]=13, dp[8]=24

## Решение

```typescript
export function tribonacci(n: number): number {
    if (n === 0) return 0;
    if (n === 1) return 0;
    if (n === 2) return 1;
    const dp = new Array(n + 1).fill(0);
    dp[0] = 0;
    dp[1] = 0;
    dp[2] = 1;
    for (let i = 3; i <= n; i++) {
        dp[i] = dp[i - 1] + dp[i - 2] + dp[i - 3]
    }
    return dp[n];
}
```

## Разбор

**Идея:** последовательно считаем трибоначчи через сумму трёх предыдущих
**Сложность:** O(n) по времени, O(n) по памяти.
