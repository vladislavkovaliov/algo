# Task6: Factorial

## Паттерн: Одномерная ДП

**Зелёные флаги:** факториал, умножение на предыдущее, 1D ДП

## Условие

Дано число n. Верни n! (факториал n).

---

**Постановка:** вычислить n! = n × (n-1) × ... × 1
**Формула:** dp[i] = i * dp[i-1]
**Что такое dp[i]?** факториал числа i
**Почему именно такой переход?** n! = n * (n-1)!
**Пошагово на примере n=6:** table: dp[0]=1, dp[1]=1, dp[2]=2, dp[3]=6, dp[4]=24, dp[5]=120, dp[6]=720

## Решение

```typescript
export function factorial(n: number): number {
    if (n === 0) return 1;
    const dp = new Array(n + 1).fill(0);
    dp[0] = 1;
    dp[1] = 1;
    for (let i = 2; i <= n; i++) {
        dp[i] = i * dp[i - 1];
    }
    return dp[n];
}
```

## Разбор

**Идея:** факториал числа n — это произведение всех чисел от 1 до n. Базовый случай: 0! = 1, 1! = 1. Каждое следующее значение получается умножением предыдущего на текущий индекс.
**Сложность:** O(n) по времени, O(n) по памяти.
