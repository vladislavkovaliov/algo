# Task24: LongestIncreasingSubsequence

## Паттерн: Одномерная ДП

**Зелёные флаги:** наибольшая возрастающая подпоследовательность, LIS, сравнение с предыдущими

## Условие

Дан массив nums. Найди длину самой длинной строго возрастающей подпоследовательности (не обязательно непрерывной).

---

**Постановка:** Дан массив nums длиной n. Нужно найти длину самой длинной строго возрастающей подпоследовательности. Элементы подпоследовательности не обязаны идти подряд, но их порядок должен сохраняться.

**Формула:** dp[i] = max(1, max(dp[j] + 1) для всех j < i, где nums[j] < nums[i])

**Что такое dp[i]?** Длина LIS, которая заканчивается на элементе nums[i].

**Почему именно такой переход?** Чтобы найти LIS, заканчивающуюся на i, перебираем все предыдущие элементы j, которые меньше nums[i]. Для каждого такого j длина LIS, заканчивающегося на j, + 1 (сам nums[i]). Берём максимум. Минимум — 1 (только сам элемент).

**Почему это ДП?** Согласно algorithm-frameworks.md: «Один массив/строка, min/max / кол-во способов → Одномерная ДП». У нас один массив nums, ищем максимум. dp[i] зависит от всех dp[j] для j < i.

**Пошагово на примере nums = [10, 9, 2, 5, 3, 7, 101, 18]:**

| i | nums[i] | dp[i] | как получилось |
|---|---------|-------|----------------|
| 0 | 10 | 1 | база |
| 1 | 9 | 1 | нет j < 1 с nums[j] < 9 |
| 2 | 2 | 1 | нет j < 2 с nums[j] < 2 |
| 3 | 5 | 2 | dp[2]+1 = 2 (2 → 5) |
| 4 | 3 | 2 | dp[2]+1 = 2 (2 → 3) |
| 5 | 7 | 3 | dp[3]+1=3, dp[4]+1=3 (2→5→7 или 2→3→7) |
| 6 | 101 | 4 | dp[5]+1=4 (2→5→7→101 или 2→3→7→101) |
| 7 | 18 | 4 | dp[5]+1=4 (2→5→7→18 или 2→3→7→18) |

Ответ: max(dp) = 4 ✅

## Решение

```typescript
export function longestIncreasingSubsequence(nums: number[]): number {
    const n = nums.length;
    if (n === 0) return 0;
    const dp = new Array(n).fill(1);
    let maxLen = 1;
    for (let i = 1; i < n; i++) {
        for (let j = 0; j < i; j++) {
            if (nums[j] < nums[i]) {
                dp[i] = Math.max(dp[i], dp[j] + 1);
            }
        }
        maxLen = Math.max(maxLen, dp[i]);
    }
    return maxLen;
}
```

## Разбор

**Идея:** Классическая LIS: для каждого элемента ищем лучший предыдущий меньший элемент и удлиняем его последовательность.

**Сложность:** O(n²) по времени, O(n) по памяти.
