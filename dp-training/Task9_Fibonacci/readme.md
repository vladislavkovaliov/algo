# Task9: Fibonacci

## Паттерн: Одномерная ДП

**Зелёные флаги:** последовательность, два предыдущих значения, числа Фибоначчи

## Условие

Дано число n. Верни n-е число Фибоначчи, где F(0)=0, F(1)=1, F(n)=F(n-1)+F(n-2).

---

**Постановка:** вычислить n-е число Фибоначчи через рекуррентную формулу
**Формула:** dp[i] = dp[i-1] + dp[i-2]
**Что такое dp[i]?** i-е число Фибоначчи
**Почему именно такой переход?** классическое определение Фибоначчи
**Пошагово на примере n=7:** dp[0]=0, dp[1]=1, dp[2]=1, dp[3]=2, dp[4]=3, dp[5]=5, dp[6]=8, dp[7]=13

## Решение

```typescript
export function fibonacci(n: number): number {
    if (n === 0) return 0;
    if (n === 1) return 1;
    const dp = new Array(n + 1).fill(0);
    dp[0] = 0;
    dp[1] = 1;
    for (let i = 2; i <= n; i++) {
        dp[i] = dp[i - 1] + dp[i - 2];
    }
    return dp[n];
}
```

## Разбор

**Идея:** используем массив dp, где dp[i] хранит i-е число Фибоначчи; последовательно заполняем от 2 до n
**Сложность:** O(n) по времени, O(n) по памяти.
