# Task18: CoinChangeFull

## Паттерн: Одномерная ДП

**Зелёные флаги:** минимальное количество монет, произвольные номиналы, неограниченное количество каждой монеты

## Условие

Даны сумма amount и массив coins — номиналы монет (каждую можно использовать сколько угодно раз). Найди минимальное количество монет, чтобы набрать ровно amount. Если невозможно — верни -1.

---

**Постановка:** Пусть dp[i] — минимальное количество монет для суммы i. База: dp[0] = 0. Для всех остальных i dp[i] = Infinity. Для каждой суммы i от 1 до amount перебираем монеты: если номинал coin <= i, то dp[i] = min(dp[i], dp[i - coin] + 1).

**Формула:** dp[i] = min(dp[i], dp[i - coin] + 1) для всех coin из coins, где coin <= i

**Что такое dp[i]?** Минимальное количество монет для суммы i.

**Почему именно такой переход?** Для суммы i перебираем каждую монету как "последнюю". Если берём монету coin, то остаётся сумма i - coin, для которой оптимальное решение — dp[i - coin]. Плюс одна монета.

**Почему это ДП?** Согласно algorithm-frameworks.md: «Один массив/строка, min/max / кол-во способов → Одномерная ДП». У нас один массив amount, ищем минимум. dp[i] считается через dp[i-coin].

**Пошагово на примере amount = 11, coins = [1, 2, 5]:**

| i | dp[i] | как получилось |
|---|-------|----------------|
| 0 | 0 | база |
| 1 | 1 | min(dp[0]+1) = 1 |
| 2 | 1 | min(dp[1]+1=2, dp[0]+1=1) = 1 |
| 3 | 2 | min(dp[2]+1=2, dp[1]+1=2) = 2 |
| 4 | 2 | min(dp[3]+1=3, dp[2]+1=2) = 2 |
| 5 | 1 | min(dp[4]+1=3, dp[3]+1=3, dp[0]+1=1) = 1 |
| 6 | 2 | min(dp[5]+1=2, dp[4]+1=3, dp[1]+1=2) = 2 |
| 7 | 2 | min(dp[6]+1=3, dp[5]+1=2, dp[2]+1=2) = 2 |
| 8 | 3 | min(dp[7]+1=3, dp[6]+1=3, dp[3]+1=3) = 3 |
| 9 | 3 | min(dp[8]+1=4, dp[7]+1=3, dp[4]+1=3) = 3 |
| 10 | 2 | ... |
| 11 | 3 | ... (5+5+1 = 3 монеты) |

## Решение

```typescript
export function coinChangeFull(amount: number, coins: number[]): number {
    const dp = new Array(amount + 1).fill(Infinity);
    dp[0] = 0;
    for (let i = 1; i <= amount; i++) {
        for (const coin of coins) {
            if (coin <= i) {
                dp[i] = Math.min(dp[i], dp[i - coin] + 1);
            }
        }
    }
    return dp[amount] === Infinity ? -1 : dp[amount];
}
```

## Разбор

**Идея:** Классическая задача о размене монет. Для каждой суммы перебираем все монеты как потенциальную последнюю монету.

**Сложность:** O(amount * len(coins)) по времени, O(amount) по памяти.
