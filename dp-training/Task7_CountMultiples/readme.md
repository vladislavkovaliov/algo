# Task7: CountMultiples

## Паттерн: Одномерная ДП

**Зелёные флаги:** подсчёт, условие на каждом шаге, 1D ДП

## Условие

Даны числа n и k. Посчитай, сколько чисел от 1 до n делятся на k.

---

**Постановка:** нужно посчитать количество чисел на отрезке [1, n], которые кратны k. Это простейшая задача на линейный проход с накоплением результата.

**Формула:**
dp[i] = dp[i-1] + 1, если i % k === 0
dp[i] = dp[i-1], иначе

**Что такое dp[i]?** количество чисел от 1 до i, которые делятся на k

**Почему именно такой переход?** для числа i: если делится на k — добавляем 1 к предыдущему результату, иначе просто переносим результат

**Пошагово на примере n=10, k=3:** dp[0]=0, dp[1]=0, dp[2]=0, dp[3]=1, dp[4]=1, dp[5]=1, dp[6]=2, dp[7]=2, dp[8]=2, dp[9]=3, dp[10]=3

## Решение

```typescript
export function countMultiples(n: number, k: number): number {
    if (n === 0) return 0;
    const dp = new Array(n + 1).fill(0);
    dp[0] = 0;
    for (let i = 1; i <= n; i++) {
        if(i % k === 0) {
            dp[i] = dp[i - 1] + 1;
        } else {
            dp[i] = dp[i - 1];
        }
    }
    return dp[n];
}
```

## Разбор

**Идея:** идём от 1 до n, на каждом шаге проверяем делимость текущего числа на k. Если делится — увеличиваем счётчик на 1, иначе оставляем без изменений.

**Сложность:** O(n) по времени, O(n) по памяти.
