# Task23: IsSubsetSumPossible

## Паттерн: Одномерная ДП (boolean)

**Зелёные флаги:** подмножество, сумма, можно ли набрать, boolean ДП

## Условие

Дан массив nums и число target. Можно ли выбрать подмножество чисел из nums (каждое не более одного раза), чтобы их сумма была ровна target?

---

## 2D-подход (интуитивный)

Как мы представляем решение «на пальцах»? Берём числа по одному и для каждого решаем: **брать или не брать**.

**Что такое dp[i][s]?**  
true, если из первых i чисел массива можно набрать сумму s.

**Формула:**
```
dp[i][s] = dp[i-1][s]           (не берём nums[i-1])
           OR
           dp[i-1][s - nums[i-1]]  (берём nums[i-1], если он ≤ s)
```

- **Не берём** число → переносим результат из предыдущей строки.
- **Берём** число → смотрим, можно ли было набрать остаток s - nums[i-1] без этого числа.

**База:** `dp[0][0] = true` (пустое множество даёт сумму 0), остальные `dp[0][s] = false`.

**Пошагово на примере `target = 5, nums = [2, 3]:**

| i | num | 0 | 1 | 2 | 3 | 4 | 5 |
|---|-----|----|---|---|---|---|---|
| 0 | — | T | . | . | . | . | . |
| 1 | 2 | T | . | T | . | . | . |
| 2 | 3 | T | . | T | T | . | T |

Как заполняется строка i=2 (num=3):
- `dp[2][0] = dp[1][0]` → T (не берём 3)
- `dp[2][1] = dp[1][1]` → F
- `dp[2][2] = dp[1][2]` → T (не берём 3)
- `dp[2][3] = dp[1][3] OR dp[1][0]` → F OR T → T (**берём** 3, остаток 0)
- `dp[2][4] = dp[1][4] OR dp[1][1]` → F OR F → F
- `dp[2][5] = dp[1][5] OR dp[1][2]` → F OR T → T (**берём** 3 на сумму 2)

Ответ: `dp[2][5] = true` ✅ (2 + 3 = 5)

**Код 2D-версии (для понимания):**

```typescript
export function isSubsetSumPossible2D(target: number, nums: number[]): boolean {
    const n = nums.length;
    const dp = Array.from({ length: n + 1 }, () => new Array(target + 1).fill(false));

    dp[0][0] = true;  // пустое множество → сумма 0

    for (let i = 1; i <= n; i++) {
        for (let s = 0; s <= target; s++) {
            dp[i][s] = dp[i - 1][s];  // не берём nums[i-1]

            if (nums[i - 1] <= s) {
                dp[i][s] = dp[i][s] || dp[i - 1][s - nums[i - 1]];  // берём
            }
        }
    }

    return dp[n][target];
}
```

## Оптимизация до 1D

Заметим: строка `i` использует только строку `i-1`. Нам не нужен весь двумерный массив — достаточно **одного массива**, который мы обновляем для каждого числа.

**Почему проход справа налево?**

Если обновлять массив слева направо, то на шаге `s` значение `dp[s - num]` может уже относиться к текущему числу (мы его только что обновили). Тогда мы как бы «используем» число второй раз, что запрещено.

Проход справа налево гарантирует: когда мы читаем `dp[s - num]`, это значение ещё не обновлено для текущего числа, то есть соответствует предыдущей строке.

**Код 1D (оптимизированный):**

```typescript
export function isSubsetSumPossible(target: number, nums: number[]): boolean {
    const dp = new Array(target + 1).fill(false);
    dp[0] = true;

    for (const num of nums) {
        for (let s = target; s >= num; s--) {
            if (dp[s - num]) {
                dp[s] = true;
            }
        }
    }

    return dp[target];
}
```

**1D-версия делает ровно то же самое, что 2D, но не хранит всю историю — только текущий срез.**

---

## Разбор

**Идея:** Классическая задача о сумме подмножества (0/1 knapsack). Для каждого числа решаем: брать или не брать. 2D-таблица наглядно показывает процесс. Оптимизация до 1D убирает лишнюю память, но требует прохода справа налево, чтобы не использовать число дважды.

**Сложность:** O(target * len(nums)) по времени, O(target) по памяти (1D-версия).
