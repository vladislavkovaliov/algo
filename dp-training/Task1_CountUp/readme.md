# Task1: CountUp

## Паттерн: Одномерная ДП

**Зелёные флаги:** считать до n, одно действие, 1D ДП

## Условие

Дано число n. Нужно вернуть n (посчитать от 0 до n).

---

**Постановка:** просто посчитать от 0 до n, каждый шаг +1

**Формула:**
```
dp[i] = dp[i-1] + 1
```

**Что такое dp[i]?** минимальное/текущее значение в точке i (i — это число от 0 до n)

**Почему именно такой переход?** чтобы получить i, нужно к i-1 прибавить 1

**Почему это ДП?** фреймворк говорит «один массив, считаем количество → 1D ДП» — задача разбивается на подзадачи

**Пошагово на примере n=5:**

| i | dp[i] | как получилось |
|---|---|---|
| 0 | 0 | база |
| 1 | 1 | dp[0] + 1 |
| 2 | 2 | dp[1] + 1 |
| 3 | 3 | dp[2] + 1 |
| 4 | 4 | dp[3] + 1 |
| 5 | 5 | dp[4] + 1 |

## Решение

```typescript
export function countUp(n: number): number {
    if (n === 0) return 0;
    const dp = new Array(n + 1).fill(0);
    dp[0] = 0;
    for (let i = 1; i <= n; i++) {
        dp[i] = dp[i - 1] + 1;
    }
    return dp[n];
}
```

## Разбор

**Идея:** используем массив dp, где dp[i] хранит текущее значение на шаге i. Заполняем последовательно от 1 до n, каждый раз прибавляя единицу к предыдущему значению.

**Сложность:** O(n) по времени, O(n) по памяти.
