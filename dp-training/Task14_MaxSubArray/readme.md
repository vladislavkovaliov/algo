# Task14: MaxSubArray

## Паттерн: Одномерная ДП

**Зелёные флаги:** максимальная сумма подмассива, Кадан, 1D ДП

## Условие

Дан массив nums. Найди максимальную сумму среди всех непрерывных подмассивов (хотя бы один элемент).

---

**Постановка:** максимальная сумма непрерывного подмассива в массиве nums
**Формула:** dp[i] = max(nums[i], dp[i-1] + nums[i])
**Что такое dp[i]?** максимальная сумма подмассива, который заканчивается на позиции i
**Почему именно такой переход?** для каждого i есть два варианта: начать новый подмассив с nums[i], или продолжить предыдущий подмассив dp[i-1] + nums[i]. Выбираем максимум.
**Почему это ДП?** фреймворк: один массив, ищем максимум → 1D ДП. dp[i] зависит только от dp[i-1] и nums[i].
**Пошагово на примере nums = [-2, 1, -3, 4, -1, 2, 1, -5, 4]:**

| i | nums[i] | dp[i] | max |
|---|---------|-------|-----|
| 0 | -2 | -2 | -2 |
| 1 | 1 | 1 | 1 |
| 2 | -3 | -2 | 1 |
| 3 | 4 | 4 | 4 |
| 4 | -1 | 3 | 4 |
| 5 | 2 | 5 | 5 |
| 6 | 1 | 6 | 6 |
| 7 | -5 | 1 | 6 |
| 8 | 4 | 5 | 6 |

## Решение

```typescript
export function maxSubArray(nums: number[]): number {
    const n = nums.length;
    if (n === 1) return nums[0];
    const dp = new Array(n).fill(-Infinity);
    dp[0] = nums[0];
    let max = -Infinity;
    for (let i = 1; i < n; i++) {
        dp[i] = Math.max(nums[i], dp[i - 1] + nums[i]);
        max = Math.max(dp[i], max);
    }
    return max;
}
```

## Разбор

**Идея:** Алгоритм Кадана. Для каждого элемента решаем: начать новый подмассив или продолжить старый. Ответ — максимум среди всех dp[i].

**Сложность:** O(n) по времени, O(n) по памяти. Можно оптимизировать до O(1).
