# Task20: CanReachSumWithTwo

## Паттерн: Одномерная ДП (boolean, 0/1)

**Зелёные флаги:** два числа, каждое не более одного раза, можно ли набрать сумму, 0/1

## Условие

Даны числа target, a и b. Каждое из чисел a и b можно взять **не более одного раза**. Можно ли набрать сумму target, выбирая подмножество из {a, b}?

---

**Постановка:** У нас ровно 2 числа. Каждое можно взять или не взять. Нужно проверить все возможные комбинации. Решаем через ДП, чтобы подготовиться к Task23 (SubsetSum с N числами).

**Формула:**
```
dp[i] = dp[i] || dp[i - a]   (если a <= i)
dp[i] = dp[i] || dp[i - b]   (если b <= i)
```

**Что такое dp[i]?** true, если сумму i можно набрать, используя уже обработанные числа (каждое ≤ 1 раза).

**Почему проход справа налево?** Каждое число можно использовать не более одного раза (0/1). Если идти слева направо, то, обновив dp[i] для a, мы потом можем использовать это же a снова для бóльших i на той же итерации — получится, что a использовано дважды. Проход справа налево исключает это.

**Почему это ДП?** Согласно algorithm-frameworks.md: «Один массив/строка, min/max / кол-во способов → Одномерная ДП». Здесь boolean-версия с ограничением 0/1.

**Пошагово на примере target = 7, a = 2, b = 5:**

Начало: dp = [T, F, F, F, F, F, F, F]

Итерация 1 (число a=2, справа налево):
- i=7: dp[7] ||= dp[5] = F
- i=6: dp[6] ||= dp[4] = F
- i=5: dp[5] ||= dp[3] = F
- i=4: dp[4] ||= dp[2] = F
- i=3: dp[3] ||= dp[1] = F
- i=2: dp[2] ||= dp[0] = T → dp = [T, F, T, F, F, F, F, F]

Итерация 2 (число b=5, справа налево):
- i=7: dp[7] ||= dp[2] = T → dp = [T, F, T, F, F, F, F, T]

Ответ: dp[7] = true ✅ (2 + 5 = 7)

## Решение

```typescript
export function canReachSumWithTwo(target: number, a: number, b: number): boolean {
    const dp = new Array(target + 1).fill(false);
    dp[0] = true;

    for (const num of [a, b]) {
        for (let i = target; i >= num; i--) {
            if (dp[i - num]) {
                dp[i] = true;
            }
        }
    }

    return dp[target];
}
```

## Разбор

**Идея:** Вводится ключевое понятие «каждое число не более одного раза» (0/1 knapsack). Решение — то же, что в CoinChangeBoolean, но проход справа налево. Это прямой мостик к Task23 (полный SubsetSum), где чисел N штук.

**Сложность:** O(target * 2) = O(target) по времени, O(target) по памяти.
