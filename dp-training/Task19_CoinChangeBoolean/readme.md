# Task19: CoinChangeBoolean

## Паттерн: Одномерная ДП (boolean)

**Зелёные флаги:** монеты, можно ли набрать сумму, неограниченное количество, boolean

## Условие

Дан массив coins — номиналы монет (каждую можно использовать сколько угодно раз) и целевая сумма amount. Можно ли набрать ровно amount?

---

**Постановка:** Нужно проверить, достижима ли сумма amount. Разница с Task18 (CoinChangeFull) — не нужно считать количество монет, только true/false.

**Формула:**
dp[i] = dp[i] || dp[i - coin] для всех coin из coins, где coin <= i

**Что такое dp[i]?** true, если сумму i можно набрать из неограниченного количества монет.

**Почему именно такой переход?** Если мы уже умеем набирать сумму i - coin, то добавив одну монету coin, получим сумму i. Перебираем все монеты как «последнюю добавленную».

**Почему проход слева направо?** Монеты можно использовать сколько угодно раз (unbounded). Когда мы на шаге i уже обновили dp[i], это значение может использоваться для бóльших i — это нормально, так мы учитываем многократное использование одной монеты.

**Почему это ДП?** Согласно algorithm-frameworks.md: «Один массив/строка, min/max / кол-во способов → Одномерная ДП». Boolean — частный случай подсчёта (достижимо / недостижимо).

**Пошагово на примере amount = 11, coins = [1, 2, 5]:**

| i | dp[i] | как получилось |
|---|-------|----------------|
| 0 | true | база |
| 1 | true | dp[0] → +1 |
| 2 | true | dp[1]→+1 или dp[0]→+2 |
| 3 | true | dp[2]→+1 или dp[1]→+2 |
| 4 | true | dp[3]→+1 или dp[2]→+2 |
| 5 | true | dp[4]→+1 или dp[3]→+2 или dp[0]→+5 |
| 6 | true | dp[5]→+1 или dp[4]→+2 или dp[1]→+5 |
| 7 | true | dp[6]→+1 или dp[5]→+2 или dp[2]→+5 |
| 8 | true | dp[7]→+1 или dp[6]→+2 или dp[3]→+5 |
| 9 | true | dp[8]→+1 или dp[7]→+2 или dp[4]→+5 |
| 10 | true | dp[9]→+1 или dp[8]→+2 или dp[5]→+5 |
| 11 | true | dp[10]→+1 или dp[9]→+2 или dp[6]→+5 |

Ответ: true ✅ (5+5+1 = 11)

## Решение

```typescript
export function coinChangeBoolean(amount: number, coins: number[]): boolean {
    const dp = new Array(amount + 1).fill(false);
    dp[0] = true;

    for (let i = 1; i <= amount; i++) {
        for (const coin of coins) {
            if (coin <= i && dp[i - coin]) {
                dp[i] = true;
                break;
            }
        }
    }

    return dp[amount];
}
```

## Разбор

**Идея:** Та же структура, что в Task18 (CoinChangeFull), но вместо подсчёта минимума — проверка достижимости. Это делает задачу чуть проще: не нужно сравнивать числа, достаточно найти хотя бы один способ.

**Сложность:** O(amount * len(coins)) по времени, O(amount) по памяти.
