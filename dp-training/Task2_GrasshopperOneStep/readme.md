# Task2: GrasshopperOneStep

## Паттерн: Одномерная ДП

**Зелёные флаги:** количество способов, один шаг за раз, 1D ДП

## Условие

Кузнечик стоит в точке 0 и может прыгать на 1 шаг вперёд. Сколько существует способов добраться до точки n?

---

**Постановка:** дано n — целевая точка. Кузнечик делает шаги длины 1. Найти количество различных способов достичь точки n.
**Формула:** `dp[i] = dp[i - 1]`
**Что такое dp[i]?** количество способов добраться до точки i
**Почему именно такой переход?** из i-1 можно прыгнуть только на 1, поэтому количество способов добраться до i равно количеству способов добраться до i-1.
**Почему это ДП?** фреймворк «один массив, количество способов» → 1D ДП
**Пошагово на примере n = 4:**

| i | dp[i] | объяснение                |
|---|-------|---------------------------|
| 0 | 1     | стартовая точка           |
| 1 | 1     | 1 способ: (0→1)           |
| 2 | 1     | 1 способ: (0→1→2)         |
| 3 | 1     | 1 способ: (0→1→2→3)       |
| 4 | 1     | 1 способ: (0→1→2→3→4)     |

## Решение

```typescript
export function grasshopperOneStep(n: number): number {
    if (n === 0) return 1;
    const dp = new Array(n + 1).fill(0);
    dp[0] = 1;
    for (let i = 1; i <= n; i++) {
        dp[i] = dp[i - 1];
    }
    return dp[n];
}
```

## Разбор

**Идея:** каждый способ добраться до i однозначно продолжает способ добраться до i-1, так как доступен только шаг длины 1.
**Сложность:** O(n) по времени, O(n) по памяти
