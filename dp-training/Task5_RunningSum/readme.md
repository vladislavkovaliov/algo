# Task5: RunningSum

## Паттерн: Одномерная ДП

**Зелёные флаги:** сумма от 1 до n, последовательное накопление, 1D ДП

## Условие

Дано число n. Найди сумму чисел от 1 до n (без формулы арифметической прогрессии).

---

**Постановка:** рекуррентное соотношение: чтобы узнать сумму до i, нужно знать сумму до i-1 и прибавить i.
**Формула:** dp[i] = dp[i-1] + i
**Что такое dp[i]?** сумма чисел от 1 до i
**Почему именно такой переход?** чтобы получить сумму до i, берём сумму до i-1 и прибавляем i
**Пошагово на примере n=5:** dp[0]=0, dp[1]=1, dp[2]=3, dp[3]=6, dp[4]=10, dp[5]=15

## Решение

```typescript
export function runningSum(n: number): number {
    if (n === 0) return 0;
    const dp = new Array(n + 1).fill(0);
    dp[0] = 0;
    dp[1] = 1;
    for (let i = 2; i <= n; i++) {
        dp[i] = dp[i - 1] + i;
    }
    return dp[n];
}
```

## Разбор

**Идея:** используем динамическое программирование — массив dp, где dp[i] хранит сумму чисел от 1 до i. Базовый случай: dp[0] = 0, dp[1] = 1. Далее для каждого i от 2 до n вычисляем dp[i] через предыдущее значение.
**Сложность:** O(n) по времени, O(n) по памяти.
