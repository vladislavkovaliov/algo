# Task15: ExactChangeTwoCoins

## Паттерн: Одномерная ДП

**Зелёные флаги:** минимальное количество монет, ровно два номинала (2 и 5), задача о размене

## Условие

Дана сумма amount. Используя монеты номиналом 2 и 5 (каждую можно использовать сколько угодно раз), набери ровно amount минимальным количеством монет. Если невозможно — верни -1.

---

**Постановка:** ...
**Формула:** dp[i] = min(dp[i-2] + 1, dp[i-5] + 1)
**Что такое dp[i]?** минимальное количество монет для суммы i
**Почему именно такой переход?** для суммы i последняя монета могла быть 2 или 5. Берём минимум из двух вариантов.
**Почему это ДП?** фреймворк: один массив, ищем минимум → 1D ДП. dp[i] зависит от dp[i-2] и dp[i-5].
**Пошагово на примере amount=10:** table: dp[0]=0, dp[1]=-1, dp[2]=1, dp[3]=-1, dp[4]=2, dp[5]=1, dp[6]=3, dp[7]=2, dp[8]=4, dp[9]=3, dp[10]=2

## Решение

```typescript
export function exactChangeTwoCoins(amount: number): number {
    if (amount === 0) return 0;
    const dp = new Array(amount + 1).fill(Infinity);
    dp[0] = 0;
    for (let i = 1; i <= amount; i++) {
        for (let coin of [2, 5]) {
            if (i - coin >= 0) {
                dp[i] = Math.min(dp[i], dp[i - coin] + 1);
            }
        }
    }
    return dp[amount] === Infinity ? -1 : dp[amount];
}
```

## Разбор

**Идея:** ...
**Сложность:** O(amount) по времени (2 итерации на i), O(amount) по памяти.
