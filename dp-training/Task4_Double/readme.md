# Task4: Double

## Паттерн: Одномерная ДП

**Зелёные флаги:** удвоение, 1D ДП, последовательность степеней двойки

## Условие

Дано число n. Верни 2^n (без использования Math.pow или **).

---

**Постановка:** вычислить 2^n итеративно через предыдущее значение.
**Формула:** dp[i] = dp[i-1] * 2
**Что такое dp[i]?** 2^i
**Почему именно такой переход?** 2^i = 2^(i-1) * 2
**Почему это ДП?** фреймворк: один массив → 1D ДП. Каждое следующее значение удваивает предыдущее.
**Пошагово на примере n=5:** i=0→1, 1→2, 2→4, 3→8, 4→16, 5→32

## Решение

```typescript
export function double(n: number): number {
    if (n === 0) return 1;
    const dp = new Array(n + 1).fill(0);
    dp[0] = 1;
    for (let i = 1; i <= n; i++) {
        dp[i] = dp[i - 1] * 2;
    }
    return dp[n];
}
```

## Разбор

**Идея:** классическая одномерная ДП:每一步 удваиваем предыдущий результат.
**Сложность:** O(n) по времени, O(n) по памяти.
