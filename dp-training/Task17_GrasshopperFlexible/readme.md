# Task17: GrasshopperFlexible

## Паттерн: Одномерная ДП

**Зелёные флаги:** количество способов, произвольные шаги, сумма вариантов

## Условие

Кузнечик стоит в точке 0. Умеет прыгать на длины из allowedSteps. Сколько способов допрыгать до точки n?

---

**Постановка:** Кузнечик стоит в точке 0. Умеет прыгать только на длины из `allowedSteps`. Сколько способов допрыгать до точки N?

**Формула:**
dp[i] = sum(dp[i - step]) для всех step из allowedSteps, где step <= i
dp[0] = 1

**Что такое dp[i]?** Количество способов добраться до точки i.

**Почему именно такой переход?** Чтобы попасть в точку i, последний прыжок был на step из точки i - step. Значит, количество способов добраться до i = сумма способов добраться до всех точек, из которых можно прыгнуть в i.

**Почему это ДП?** Согласно algorithm-frameworks.md: «Один массив/строка, min/max / кол-во способов → Одномерная ДП». У нас задача о количестве способов, dp[i] считается как сумма dp[i-step] для всех шагов.

**Пошагово на примере n = 4, allowedSteps = [1, 2, 3]:**

| i | dp[i] | как получилось |
|---|-------|----------------|
| 0 | 1 | база |
| 1 | 1 | dp[0] = 1 |
| 2 | 2 | dp[1] + dp[0] = 2 |
| 3 | 4 | dp[2] + dp[1] + dp[0] = 4 |
| 4 | 7 | dp[3] + dp[2] + dp[1] = 7 |

## Решение

```typescript
export function grasshopperFlexible(n: number, allowedSteps: number[]): number {
    const dp = new Array(n + 1).fill(0);
    dp[0] = 1;
    for (let i = 1; i <= n; i++) {
        for (const step of allowedSteps) {
            if (step <= i) {
                dp[i] += dp[i - step];
            }
        }
    }
    return dp[n];
}
```

## Разбор

**Идея:** Для каждой точки суммируем количество способов из всех точек, откуда можно прыгнуть в текущую.

**Сложность:** O(n * len(allowedSteps)) по времени, O(n) по памяти.
