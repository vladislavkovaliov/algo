# Task3: ExactChangeWithOnes

## Паттерн: Одномерная ДП

**Зелёные флаги:** минимальное количество монет, монета 1 доступна всегда

## Условие

Дана сумма amount. Можно использовать монеты номиналом 1. Найди минимальное количество монет, чтобы набрать amount.

---

**Постановка:** dp[i] — минимальное количество монет для суммы i. Ищем dp[amount].

**Формула:** dp[i] = dp[i-1] + 1

**Что такое dp[i]?** минимальное количество монет для суммы i

**Почему именно такой переход?** чтобы набрать i, берём оптимальное решение для i-1 и добавляем одну монету 1

**Почему это ДП?** фреймворк: один массив, минимум → 1D ДП. dp[i] считается из dp[i-1]

**Пошагово на примере amount=5:**

| i | dp[i] | Действие |
|---|-------|----------|
| 0 | 0     | базовый случай |
| 1 | 1     | одна монета 1 |
| 2 | 2     | dp[1] + 1 |
| 3 | 3     | dp[2] + 1 |
| 4 | 4     | dp[3] + 1 |
| 5 | 5     | dp[4] + 1 |

## Решение

```typescript
export function exactChangeWithOnes(amount: number): number {
    if (amount === 0) return 0;
    const dp = new Array(amount + 1).fill(0);
    dp[0] = 0;
    dp[1] = 1;
    for (let i = 2; i <= amount; i++) {
        dp[i] = dp[i - 1] + 1
    }
    return dp[amount];
}
```

## Разбор

**Идея:** Так как доступна только монета 1, каждую единицу суммы можно закрыть одной монетой. ДП сводится к последовательному накоплению: dp[i] = dp[i-1] + 1.

**Сложность:** O(amount) по времени, O(amount) по памяти.
