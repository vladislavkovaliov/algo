# Task22: LongestNonDecreasingSubsequence

## Паттерн: Одномерная ДП (O(n²))

**Зелёные флаги:** неубывающая подпоследовательность, <=, вложенный цикл, LNDS

## Условие

Дан массив чисел. Найди длину самой длинной **неубывающей** подпоследовательности (не обязательно непрерывной). Неубывающая означает, что каждый следующий элемент ≥ предыдущего.

---

**Постановка:** Почти то же самое, что LIS (Task24), но с `<=` вместо `<`. Это позволяет одинаковым элементам следовать друг за другом.

**Формула:**
dp[i] = max(1, max(dp[j] + 1) для всех j < i, где nums[j] <= nums[i])

**Что такое dp[i]?** Длина LNDS, которая заканчивается на элементе nums[i].

**Почему именно такой переход?** Чтобы найти LNDS, заканчивающуюся на i, перебираем все предыдущие j, которые НЕ БОЛЬШЕ nums[i] (неубывание: nums[j] <= nums[i]). Для каждого такого j длина LNDS, заканчивающегося на j, + 1 (сам nums[i]).

**Чем отличается от LIS?** В LIS (Task24) условие строгое: nums[j] < nums[i]. Здесь условие нестрогое: nums[j] <= nums[i].

**Пошагово на примере nums = [1, 3, 2, 2, 4]:**

| i | nums[i] | dp[i] | как получилось |
|---|---------|-------|----------------|
| 0 | 1 | 1 | база |
| 1 | 3 | 2 | dp[0]+1 = 2 (1→3) |
| 2 | 2 | 2 | dp[0]+1 = 2 (1→2) |
| 3 | 2 | 3 | dp[2]+1 = 3 (1→2→2), dp[0]+1=2 |
| 4 | 4 | 4 | dp[3]+1 = 4 (1→2→2→4) |

Ответ: 4 ✅ (1, 2, 2, 4)

## Решение

```typescript
export function longestNonDecreasingSubsequence(nums: number[]): number {
    const n = nums.length;
    if (n === 0) return 0;

    const dp = new Array(n).fill(1);
    let maxLen = 1;

    for (let i = 1; i < n; i++) {
        for (let j = 0; j < i; j++) {
            if (nums[j] <= nums[i]) {
                dp[i] = Math.max(dp[i], dp[j] + 1);
            }
        }
        maxLen = Math.max(maxLen, dp[i]);
    }

    return maxLen;
}
```

## Разбор

**Идея:** Та же O(n²) ДП, что и в LIS, но с `<=`. Разница минимальна, но важна: в LNDS равные элементы могут стоять рядом. В отличие от Task21 (CountIncreasingSequences), здесь мы не просто считаем, а максимизируем длину.

**Сложность:** O(n²) по времени, O(n) по памяти.
