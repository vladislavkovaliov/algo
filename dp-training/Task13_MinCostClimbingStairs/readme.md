# Task13: MinCostClimbingStairs

## Паттерн: Одномерная ДП

**Зелёные флаги:** минимальная стоимость, шаг на 1 или 2, массив стоимостей

## Условие

Дан массив cost, где cost[i] — стоимость i-й ступеньки. Можно начать со ступеньки 0 или 1. На каждом шаге поднимаешься на 1 или 2 ступеньки. Найди минимальную стоимость добраться до вершины (за пределы массива).

---

**Постановка:** Нужно найти минимальную стоимость пути от низа до вершины. За каждую ступеньку, на которую встаёшь, платишь её стоимость.

**Формула:**
dp[i] = cost[i] + min(dp[i-1], dp[i-2])
Ответ: min(dp[n-1], dp[n-2])

**Что такое dp[i]?** Минимальная стоимость, чтобы добраться до ступеньки i и заплатить за неё.

**Почему именно такой переход?** На ступеньку i можно попасть только с i-1 (шаг на 1) или с i-2 (шаг на 2). Выбираем тот путь, который дешевле: min(dp[i-1], dp[i-2]). Плюс платим cost[i] за то, что встали на эту ступеньку.

**Почему ответ min(dp[n-1], dp[n-2])?** Вершина находится за последней ступенькой. Уйти за пределы массива можно либо с последней ступеньки (n-1), либо с предпоследней (n-2). Выбираем, откуда дешевле шагнуть «в никуда».

**Почему это ДП?** Согласно algorithm-frameworks.md: «Один массив/строка, min/max / кол-во способов → Одномерная ДП». У нас один массив cost, ищем минимум. Задача разбивается на подзадачи: dp[i] зависит от dp[i-1] и dp[i-2]. Решаем от меньших индексов к большим.

**Пошагово на примере cost = [10, 15, 20]:**

| i | cost[i] | dp[i] | как получилось |
|---|---------|-------|----------------|
| 0 | 10 | 10 | база: начинаем с 0 |
| 1 | 15 | 15 | база: начинаем с 1 |
| 2 | 20 | 30 | 20 + min(15, 10) = 20 + 10 = 30 |

Ответ: min(dp[2], dp[1]) = min(30, 15) = 15 ✅

## Решение

```typescript
export function minCostClimbingStairs(cost: number[]): number {
    const n = cost.length;
    if (n === 1) return cost[0];
    const dp = new Array(n).fill(0);
    dp[0] = cost[0];
    dp[1] = cost[1];
    for (let i = 2; i < n; i++) {
        dp[i] = cost[i] + Math.min(dp[i - 1], dp[i - 2]);
    }
    return Math.min(dp[n - 1], dp[n - 2]);
}
```

## Разбор

**Идея:** Идём слева направо, для каждой ступеньки запоминаем минимальную стоимость пути до неё. Выбираем лучший из двух предыдущих вариантов.

**Сложность:** O(n) по времени, O(n) по памяти.
