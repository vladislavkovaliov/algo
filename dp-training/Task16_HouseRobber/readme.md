# Task16: HouseRobber

## Паттерн: Одномерная ДП

**Зелёные флаги:** максимальная сумма, нельзя брать соседние, выбор из двух вариантов

## Условие

Дан массив nums — деньги в каждом доме. Нельзя ограбить два соседних дома. Найди максимальную сумму, которую можно унести.

---

**Постановка:** Ты — вор. Нельзя грабить два соседних дома. Найти максимальную сумму.

**Формула:**
dp[i] = max(dp[i-1], dp[i-2] + nums[i])

**Что такое dp[i]?** Максимальная сумма, которую можно унести, пройдя дома от 0 до i (не обязательно грабить i-й).

**Почему именно такой переход?**
- dp[i-1] — это вариант "не грабить дом i". Просто берём лучший результат до i-1.
- dp[i-2] + nums[i] — это вариант "ограбить дом i". Тогда дом i-1 трогать нельзя, поэтому берём лучшее без него — dp[i-2] — и прибавляем nums[i].

Почему не dp[i-1] + nums[i]? Потому что dp[i-1] мог получиться с ограблением дома i-1, и тогда будет нарушение — два соседних дома ограблены. А dp[i-2] гарантированно не соседний.

Почему не только dp[i-2] + nums[i]? Потому что выгодно иногда пропустить несколько домов подряд. Например: [5, 1, 1, 5] → лучший ответ 10 (взять 1-й и 4-й, пропустив два дома). Без dp[i-1] мы не сможем "накопить" пропуск нескольких домов.

**Почему это ДП?** Согласно algorithm-frameworks.md: «Один массив/строка, min/max / кол-во способов → Одномерная ДП». У нас один массив nums, ищем максимум. dp[i] зависит от dp[i-1] и dp[i-2] — выбираем лучший вариант.

**Пошагово на примере nums = [2, 7, 9, 3, 1]:**

| i | nums[i] | dp[i] | как получилось |
|---|---------|-------|----------------|
| 0 | 2 | 2 | база: грабим дом 0 |
| 1 | 7 | 7 | max(2, 0+7) = 7 |
| 2 | 9 | 11 | max(7, 2+9) = 11 |
| 3 | 3 | 11 | max(11, 7+3) = 11 |
| 4 | 1 | 12 | max(11, 11+1) = 12 |

Ответ: 12 ✅

## Решение

```typescript
export function houseRobber(nums: number[]): number {
    const n = nums.length;
    if (n === 1) return nums[0];
    if (n === 2) return Math.max(nums[0], nums[1]);
    const dp = new Array(n).fill(-Infinity);
    dp[0] = nums[0];
    dp[1] = Math.max(nums[0], nums[1]);
    let max = -Infinity;
    for (let i = 2; i < n; i++) {
        dp[i] = Math.max(dp[i - 1], dp[i - 2] + nums[i]);
        max = Math.max(dp[i], max)
    }
    return max;
}
```

## Разбор

**Идея:** Для каждого дома решаем: грабить его (пропуская соседний) или пропустить. Выбираем лучший вариант.

**Сложность:** O(n) по времени, O(n) по памяти.
