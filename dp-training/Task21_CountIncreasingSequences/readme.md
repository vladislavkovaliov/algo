# Task21: CountIncreasingSequences

## Паттерн: Пред-ДП (вложенный цикл)

**Зелёные флаги:** подсчёт слева, меньше текущего, вложенный цикл

## Условие

Дан массив чисел nums. Для каждой позиции i посчитай, сколько элементов слева от i (j < i) имеют значение строго меньше nums[i]. Верни массив counts, где counts[i] — количество таких j.

---

**Постановка:** Это не ДП-задача, а разминка. Она вводит паттерн «для каждого i перебираем все j < i» — тот самый O(n²), который понадобится в Task22 и Task24 (LIS).

**Формула:**
counts[i] = количество j < i, таких что nums[j] < nums[i]

**Что такое counts[i]?** Количество элементов слева от i, которые меньше nums[i].

**Почему это не ДП?** Каждый counts[i] считается независимо, без использования предыдущих counts. Это просто подсчёт.

**Зачем эта задача?** Механический навык: вложенный цикл (for i, for j). В LIS (Task24) у нас будет точно такой же вложенный цикл, но дополнительно появится максимизация dp[i] = max(dp[j] + 1).

**Пошагово на примере nums = [10, 9, 2, 5, 3, 7, 101, 18]:**

| i | nums[i] | j < i с nums[j] < nums[i] | counts[i] |
|---|---------|---------------------------|-----------|
| 0 | 10 | — | 0 |
| 1 | 9 | нет (10 > 9) | 0 |
| 2 | 2 | нет | 0 |
| 3 | 5 | nums[2]=2 < 5 | 1 |
| 4 | 3 | nums[2]=2 < 3 | 1 |
| 5 | 7 | nums[2]=2, nums[3]=5, nums[4]=3 | 3 |
| 6 | 101 | все 6 предыдущих меньше | 6 |
| 7 | 18 | nums[2]=2, nums[3]=5, nums[4]=3, nums[5]=7 | 5 |

Ответ: [0, 0, 0, 1, 1, 3, 6, 5] ✅

## Решение

```typescript
export function countIncreasingSequences(nums: number[]): number[] {
    const n = nums.length;
    const counts = new Array(n).fill(0);

    for (let i = 0; i < n; i++) {
        for (let j = 0; j < i; j++) {
            if (nums[j] < nums[i]) {
                counts[i]++;
            }
        }
    }

    return counts;
}
```

## Разбор

**Идея:** Простейший вложенный цикл. Для каждого i проходим по всем j < i и считаем подходящие.

**Связь с LIS (Task24):** Замени подсчёт на `dp[i] = max(dp[i], dp[j] + 1)` — получится LIS. Разница всего в одной строке!

**Сложность:** O(n²) по времени, O(1) дополнительной памяти (не считая выходной массив).
