# Task10: GrasshopperTwoOptions

## Паттерн: Одномерная ДП

**Зелёные флаги:** количество способов, прыжки на 1 или 2, числа Фибоначчи

## Условие

Кузнечик стоит в точке 0. За шаг может прыгнуть на 1 или 2. Сколько способов допрыгать до точки n?

---

**Постановка:** дано число n — финишная точка. Нужно найти количество различных последовательностей прыжков длины 1 или 2, сумма которых равна n.

**Формула:** dp[i] = dp[i-1] + dp[i-2]

**Что такое dp[i]?** количество способов добраться до точки i

**Почему именно такой переход?** в i можно прийти либо из i-1 (шаг на 1), либо из i-2 (шаг на 2). Складываем способы.

**Пошагово на примере n=6:** dp[0]=1, dp[1]=1, dp[2]=2, dp[3]=3, dp[4]=5, dp[5]=8, dp[6]=13

## Решение

```typescript
export function grasshopperTwoOptions(n: number): number {
    if (n === 0) return 1;
    const dp = new Array(n + 1).fill(0);
    dp[0] = 1;
    dp[1] = 1;
    for (let i = 2; i <= n; i++) {
        dp[i] = dp[i - 1] + dp[i - 2]
    }
    return dp[n];
}
```

## Разбор

**Идея:** задача сводится к числам Фибоначчи со сдвигом: dp[n] = Fib(n+1). Базовый случай dp[0] = 1 (один способ стоять на месте), dp[1] = 1. Для всех остальных точек применяем рекуррентное соотношение.

**Сложность:** O(n) по времени, O(n) по памяти.
