# Метод двух указателей: учебник с нуля

Этот учебник объясняет, как решать задачи на **два указателя** (two pointers) — один из самых частых приёмов на собеседованиях и олимпиадах.

Учебник написан так, чтобы его понял человек, который **никогда не решал алгоритмические задачи** и не знает слов «сложность», «in-place», «инвариант». Все термины вводятся по одному и сразу на примерах.

Материал построен на 20 задачах из папки [`../two-pointer`](../two-pointer). Каждая задача разобрана: идея, код, пошаговый след, доказательство, типичные ошибки.

---

## Для кого этот учебник

- Для студента, который впервые видит алгоритмы.
- Для преподавателя, которому нужен готовый курс с планом занятий, задачами и разбором ошибок.
- Для того, кто уже решает задачи, но хочет собрать приёмы в единую систему, а не запоминать решения по одному.

## Что вы освоите

После прохождения вы сможете:

1. Объяснять, что такое массив, индекс, цикл и сложность алгоритма.
2. Понимать, зачем нужны два указателя и почему это часто быстрее полного перебора.
3. Узнавать **четыре семейства** задач по «зелёным флагам» в условии.
4. Писать решения без подглядывания: от пустого файла до прохождения тестов.
5. Доказывать, что решение не пропускает правильный ответ.
6. Объяснять этот материал другим людям.

## Как читать

1. **Не пропускайте главу 1.** Большинство «непонятных» алгоритмов на самом деле упираются в непонимание индексов и циклов.
2. **Читайте с ручкой.** На каждом шаге таблицы закрывайте следующий столбец и предсказывайте, что произойдёт.
3. **Сначала идея, потом код.** Если вы поняли идею, код — это перевод на язык компьютера.
4. **Ломайте решения специально.** Меняйте `left++` на `right--`, убирайте проверку — и смотрите, какой тест упадёт. Так вы запоминаете, зачем нужна каждая строка.
5. **Прогоняйте тесты.** В корне проекта:

```bash
npm run test:tp:1     # одна задача
npm run test:tp:all   # все задачи на два указателя
```

## Условные обозначения

| Обозначение | Значение |
|-------------|----------|
| `nums`, `s`, `t` | Входные данные: массив чисел, строка, вторая строка |
| `n` | Длина массива или строки |
| `nums[i]` | Элемент массива с индексом `i` |
| `left`, `right` | Указатели, которые движутся навстречу друг другу |
| `slow`, `fast` | Указатели, которые движутся в одну сторону с разной скоростью/ролью |
| `i`, `j` | Указатели для двух разных массивов |
| O(1), O(n), O(n²) | Оценка времени работы или дополнительной памяти |
| in-place | Изменять входные данные на месте, не создавая новый массив |

## Главная мысль учебника

> Два указателя — это способ **не проверять заведомо бесполезные варианты**.

Компьютер не становится быстрее. Мы просто перестаём делать лишнюю работу. Вся магия метода — в одном вопросе:

> **«Что я теперь точно могу выбросить из рассмотрения?»**

Если вы научитесь отвечать на этот вопрос, вы сможете вывести решение сами, а не вспоминать шаблон.
