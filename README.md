# Алгоритмы: задачи и учебные материалы

Репозиторий для изучения алгоритмов на TypeScript. Здесь собраны задачи с тестами и учебники, написанные так, чтобы материал был понятен человеку, который раньше не решал алгоритмические задачи.

Новые темы добавляются в эту таблицу. Материалы по каждой теме лежат в папке [`docs/`](docs).

## Быстрый старт

```bash
npm install

npm run test:tp:1     # одна задача по два указателям
npm run test:tp:all   # все задачи по два указателям
npm run test:watch    # все задачи проекта в режиме наблюдения
```

`npm run test:watch` запускает все тесты и перезапускает их при изменении файлов.

## Как устроены задачи

Каждая задача находится в отдельной папке `TaskN_Name` и содержит:

- `solution.ts` — файл с решением;
- `solution.test.ts` — тесты;
- `readme.md` — разбор задачи: идея, код, пошаговый след, сложность и типичные ошибки.

## Как добавить новую тему

1. Создайте материалы в `docs/` — отдельным файлом или папкой.
2. Добавьте строку в таблицу «Учебники» выше.
3. Если у темы есть задачи, добавьте её в таблицу «Темы и задачи» и создайте команду запуска в `package.json`.
