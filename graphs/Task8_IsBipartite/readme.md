# Task8: IsBipartite

## Паттерн: Обход компонент связанности (BFS + раскраска)

**Зелёные флаги:** раскрасить в два цвета, соседние разных цветов, проверка графа

## Условие

Дан граф (список смежности). Определи, можно ли раскрасить узлы в два цвета так, чтобы каждое ребро соединяло узлы разных цветов.

---

**Постановка:** запускаем BFS из каждой непосещённой вершины, красим в 0, соседей — в 1. Если находим соседа того же цвета — граф не двудольный.
**Почему это Графы?** Классическая задача на BFS-раскраску (обход компонент).
**Пошагово на примере [[1,3],[0,2],[1,3],[0,2]]:**
- Красим 0 в красный, соседей {1,3} в синий
- Из 1: соседи 0 (красный — ок), 2 (не покрашен → красим в красный)
- Из 3: соседи 0 (красный — ок), 2 (красный — ок)
- Из 2: соседи 1 (синий — ок), 3 (синий — ок)
- Все рёбра соединяют разные цвета → true

## Решение

```typescript
export function isBipartite(graph: number[][]): boolean {
    const n = graph.length;
    const color = new Array(n).fill(-1);

    for (let i = 0; i < n; i++) {
        if (color[i] !== -1) continue;

        color[i] = 0;
        const queue = [i];

        while (queue.length > 0) {
            const node = queue.shift()!;
            for (const neighbor of graph[node]) {
                if (color[neighbor] === -1) {
                    color[neighbor] = 1 - color[node];
                    queue.push(neighbor);
                } else if (color[neighbor] === color[node]) {
                    return false;
                }
            }
        }
    }

    return true;
}
```

## Разбор

**Идея:** BFS-раскраска. Если сосед того же цвета → граф не двудольный.
**Сложность:** O(n + e) по времени, O(n) по памяти.
