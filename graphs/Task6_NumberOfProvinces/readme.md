# Task6: NumberOfProvinces

## Паттерн: Обход компонент связанности (DFS)

**Зелёные флаги:** матрица смежности, связанные города, количество компонент

## Условие

Дана матрица смежности `isConnected` размером n × n. Если `isConnected[i][j] = 1`, то город i соединён с городом j. Найди количество провинций (компонент связности).

---

**Постановка:** провинция = компонента связности. Запускаем DFS для каждого непосещённого города, помечаем всю компоненту.
**Что мы считаем?** Количество запусков DFS.
**Почему это Графы?** Каждый город — узел, связь — ребро. Нужно количество компонент.
**Пошагово на примере [[1,1,0],[1,1,0],[0,0,1]]:**
- Город 0: посещаем → находим 1 → помечаем {0,1} — запусков = 1
- Город 1: уже посещён
- Город 2: не посещён → запускаем DFS → запусков = 2

## Решение

```typescript
export function numberOfProvinces(isConnected: number[][]): number {
    const n = isConnected.length;
    const visited = new Array(n).fill(false);
    let count = 0;

    function dfs(city: number): void {
        visited[city] = true;
        for (let neighbor = 0; neighbor < n; neighbor++) {
            if (isConnected[city][neighbor] === 1 && !visited[neighbor]) {
                dfs(neighbor);
            }
        }
    }

    for (let i = 0; i < n; i++) {
        if (!visited[i]) {
            count++;
            dfs(i);
        }
    }

    return count;
}
```

## Разбор

**Идея:** классический подсчёт компонент связности через DFS по матрице смежности.
**Сложность:** O(n²) по времени (проходим всю матрицу), O(n) по памяти (visited).
