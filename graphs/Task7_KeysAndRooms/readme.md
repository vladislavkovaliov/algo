# Task7: KeysAndRooms

## Паттерн: Обход компонент связанности (DFS/BFS)

**Зелёные флаги:** список смежности, обход, можно ли достичь все узлы

## Условие

Стартуем из комнаты 0. В каждой комнате набор ключей — индексы других комнат, которые можно открыть. Верни `true`, если можно посетить все комнаты.

---

**Постановка:** rooms — это список смежности. Проверить, достижимы ли все узлы из узла 0.
**Алгоритм:** BFS или DFS из комнаты 0, собираем посещённые комнаты, сравниваем с n.
**Почему это Графы?** Комнаты = узлы, ключи = рёбра. Нужна достижимость всех узлов из стартового.
**Пошагово на примере [[1],[2],[3],[]]:**
- Начинаем с 0 → берём ключ 1
- Идём в 1 → берём ключ 2
- Идём в 2 → берём ключ 3
- Идём в 3 → ключей нет
- Посетили все 4 комнаты → true

## Решение

```typescript
export function canVisitAllRooms(rooms: number[][]): boolean {
    const n = rooms.length;
    const visited = new Array(n).fill(false);
    const stack = [0];
    visited[0] = true;
    let count = 1;

    while (stack.length > 0) {
        const room = stack.pop()!;
        for (const key of rooms[room]) {
            if (!visited[key]) {
                visited[key] = true;
                stack.push(key);
                count++;
            }
        }
    }

    return count === n;
}
```

## Разбор

**Идея:** DFS (или BFS) из стартового узла, считаем сколько узлов посетили.
**Сложность:** O(n + k) по времени, O(n) по памяти, где k — общее количество ключей.
