# Task4: FindCenterOfStarGraph

## Паттерн: Обход компонент связанности / Простая задача

**Зелёные флаги:** звездообразный граф, центр, одно ребро на не-центр

## Условие

Дан звездообразный граф. Найди центр (узел, который повторяется в каждом ребре).

---

**Постановка:** центр — узел, который встречается в каждом ребре. Достаточно проверить первые два ребра: центр — тот узел, который есть в обоих.
**Почему это Графы?** Простая разминка на графовую структуру.
**Пошагово на примере [[1,2],[2,3],[4,2]]:**
- Первые два ребра: [1,2] и [2,3]
- Общий узел: 2 → это центр

## Решение

```typescript
export function findCenter(edges: number[][]): number {
    const [a, b] = edges[0];
    const [c, d] = edges[1];
    return a === c || a === d ? a : b;
}
```

## Разбор

**Идея:** В звезде центр входит во все рёбра. Достаточно сравнить узлы из первых двух рёбер.
**Сложность:** O(1) по времени и памяти.
