# Task 1: MaxAverageSubarrayK

## Паттерн: Окно фиксированной длины

**Зелёные флаги:** k, фиксированная длина окна, найти среднее

## Условие

Дан массив nums и число k. Найди максимальное среднее арифметическое подмассива длины k.

## Решение

```typescript
export function maxAverageSubarray(nums: number[], k: number): number {
    let sum = 0;

    for (let i = 0; i < k; i++) {
        sum += nums[i];
    }

    let maxSum = sum;

    for (let i = k; i < nums.length; i++) {
        sum += nums[i] - nums[i - k];
        if (sum > maxSum) maxSum = sum;
    }

    return maxSum / k;
}
```

## Разбор

**Идея:** Сначала считаем сумму первого окна. Затем скользим: вычитаем левый элемент, добавляем правый.

**Пошагово на примере `nums = [1, 12, -5, -6, 50, 3]`, `k = 4`:**

| Шаг | Окно | Сумма | maxSum |
|-----|------|-------|--------|
| 0 | [1, 12, -5, -6] | 2 | 2 |
| 1 | [12, -5, -6, 50] | 51 | 51 |
| 2 | [-5, -6, 50, 3] | 42 | 51 |

Ответ: `51 / 4 = 12.75`.

**Сложность:** O(n) по времени, O(1) по памяти.
