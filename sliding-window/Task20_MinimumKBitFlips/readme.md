# Task 20: MinimumKBitFlips

## Паттерн: Окно фиксированной длины

**Зелёные флаги:** k, битовый массив, минимальное количество переворотов

## Условие

Дан массив nums из 0 и 1 и число k. За одну операцию можно перевернуть k элементов подряд (0→1, 1→0). Найди минимальное количество операций, чтобы все элементы стали равны 1. Если невозможно — верни -1.

## Решение

```typescript
export function minimumKBitFlips(nums: number[], k: number): number {
    const flipped = new Array(nums.length).fill(0);
    let flips = 0;
    let flipCount = 0;

    for (let i = 0; i < nums.length; i++) {
        if (i >= k) {
            flipCount ^= flipped[i - k];
        }

        const current = nums[i] ^ flipCount;

        if (current === 0) {
            if (i + k > nums.length) return -1;
            flips++;
            flipCount ^= 1;
            flipped[i] = 1;
        }
    }

    return flips;
}
```

## Разбор

**Идея:** Жадный подход — просматриваем слева направо. Если текущий элемент 0 (с учётом предыдущих флипов) — переворачиваем окно начиная с i. Отслеживаем активные флипы через flipCount и массив flipped.

**Пошагово на примере `nums = [0, 0, 0, 1, 0, 1, 1, 0]`, `k = 3`:**

| i | nums[i] | flipCount | current | = 0? | Действие | flips |
|---|---------|-----------|---------|------|----------|-------|
| 0 | 0 | 0 | 0 | ✅ | flip[0..2], flipCount=1 | 1 |
| 1 | 0 | 1 | 1 | Нет | — | 1 |
| 2 | 0 | 1 | 1 | Нет | — | 1 |
| 3 | 1 | 1 | 0 | ✅ | flip[3..5], flipCount=0, flipped[0] вышла | 2 |
| 4 | 0 | 0 | 0 | ✅ | flip[4..6], flipCount=1 | 3 |
| 5 | 1 | 1 | 0 | ✅ | i+k=8 > 8? нет, flip[5..7], flipCount=0 | 4 |

Ой, тут получилось 4 переворота, а ожидается 3. Давайте перепроверим.

На самом деле тест `[0,0,0,1,0,1,1,0], 3` ожидает 3. Давайте проверим правильность решения:

На самом деле правильное решение должно давать 3 для этого теста. Нужно учесть, что после переворота все элементы меняются, и предыдущий flipped[i-k] вычитается. 

Давайте перетрассируем правильно:

| i | nums[i] | flipCount | current | = 0? | Действие | flips |
|---|---------|-----------|---------|------|----------|-------|
| 0 | 0 | 0 | 0 | ✅ | flip[0..2], flipCount=1, flipped[0]=1 | 1 |
| 1 | 0 | 1 (0+1) | 1 | Нет | — | 1 |
| 2 | 0 | 1 | 1 | Нет | — | 1 |
| 3 | 1 | 1 (flipped[0]=1 выходит → 1^1=0) | 1 | Нет | — | 1 |
| 4 | 0 | 0 | 0 | ✅ | flip[4..6], flipCount=1, flipped[4]=1 | 2 |
| 5 | 1 | 1 | 0 | ✅ | flip[5..7], flipCount=0, flipped[5]=1 | 3 |
| 6 | 1 | 0 | 1 | Нет | — | 3 |

Так, получается flip[5..7] меняет элемент 5 с 1 на 0, а элемент 7 с 0 на 1. Пвсе 1. Ответ: 3. ✅

**Сложность:** O(n) по времени, O(n) по памяти.
