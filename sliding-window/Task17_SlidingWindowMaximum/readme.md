# Task 17: SlidingWindowMaximum

## Паттерн: Окно фиксированной длины

**Зелёные флаги:** k, максимум в окне, дека (deque)

## Условие

Дан массив nums и число k. Найди максимум в каждом подмассиве длины k.

## Решение

```typescript
export function slidingWindowMaximum(nums: number[], k: number): number[] {
    const result: number[] = [];
    const deque: number[] = [];

    for (let i = 0; i < nums.length; i++) {
        while (deque.length > 0 && deque[deque.length - 1] < nums[i]) {
            deque.pop();
        }

        deque.push(nums[i]);

        if (i >= k - 1) {
            result.push(deque[0]);
            if (deque[0] === nums[i - k + 1]) {
                deque.shift();
            }
        }
    }

    return result;
}
```

## Разбор

**Идея:** Храним в деке элементы в убывающем порядке. Первый в деке — максимум текущего окна.

**Пошагово на примере `nums = [1, 3, -1, -3, 5, 3, 6, 7]`, `k = 3`:**

| i | nums[i] | deque (→) | Окно | max |
|---|---------|-----------|------|-----|
| 0 | 1 | [1] | — | — |
| 1 | 3 | [3] (1 вытолкнут) | — | — |
| 2 | -1 | [3, -1] | [1,3,-1] | 3 |
| 3 | -3 | [3, -1, -3] | [3,-1,-3] | 3 |
| 4 | 5 | [5] (все вытолкнуты) | [-1,-3,5] | 5 |
| 5 | 3 | [5, 3] | [-3,5,3] | 5 |
| 6 | 6 | [6] (все вытолкнуты) | [5,3,6] | 6 |
| 7 | 7 | [7] | [3,6,7] | 7 |

Ответ: `[3, 3, 5, 5, 6, 7]`.

**Сложность:** O(n) по времени, O(k) по памяти.
