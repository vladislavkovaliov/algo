# Task 2: MaxSumSubarrayK

## Паттерн: Окно фиксированной длины

**Зелёные флаги:** k, фиксированная длина окна, максимальная сумма

## Условие

Дан массив nums и число k. Найди максимальную сумму подмассива длины k.

## Решение

```typescript
export function maxSumSubarray(nums: number[], k: number): number {
    let sum = 0;

    for (let i = 0; i < k; i++) {
        sum += nums[i];
    }

    let maxSum = sum;

    for (let i = k; i < nums.length; i++) {
        sum += nums[i] - nums[i - k];
        if (sum > maxSum) maxSum = sum;
    }

    return maxSum;
}
```

## Разбор

**Идея:** Та же техника скользящего окна, что и в Task 1, но без деления на k.

**Пошагово на примере `nums = [2, 7, 3, 0, 6, 1, -5]`, `k = 3`:**

| Шаг | Окно | Сумма | maxSum |
|-----|------|-------|--------|
| 0 | [2, 7, 3] | 12 | 12 |
| 1 | [7, 3, 0] | 10 | 12 |
| 2 | [3, 0, 6] | 9 | 12 |
| 3 | [0, 6, 1] | 7 | 12 |
| 4 | [6, 1, -5] | 2 | 12 |

Ответ: `12`.

**Сложность:** O(n) по времени, O(1) по памяти.
