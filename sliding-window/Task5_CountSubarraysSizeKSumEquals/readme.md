# Task 5: CountSubarraysSizeKSumEquals

## Паттерн: Окно фиксированной длины

**Зелёные флаги:** k, фиксированная длина окна, количество подмассивов, сумма

## Условие

Дан массив nums, число k и target. Найди количество подмассивов длины k, сумма которых равна target.

## Решение

```typescript
export function countSubarraysSizeKSumEquals(nums: number[], k: number, target: number): number {
    let sum = 0;
    let count = 0;

    for (let i = 0; i < k; i++) {
        sum += nums[i];
    }

    if (sum === target) count++;

    for (let i = k; i < nums.length; i++) {
        sum += nums[i] - nums[i - k];
        if (sum === target) count++;
    }

    return count;
}
```

## Разбор

**Идея:** Скользим окном длины k, для каждого считаем сумму и сравниваем с target.

**Пошагово на примере `nums = [1, 2, 3, 4, 5]`, `k = 2`, `target = 5`:**

| Шаг | Окно | Сумма | Совпадает? | count |
|-----|------|-------|-----------|-------|
| 0 | [1, 2] | 3 | Нет | 0 |
| 1 | [2, 3] | 5 | Да ✅ | 1 |
| 2 | [3, 4] | 7 | Нет | 1 |
| 3 | [4, 5] | 9 | Нет | 1 |

Ответ: `2` (но по факту у нас получилось 1 🤔 — давайте проверим).

Проверяем: `[1,4]` нет длины 2. `[2,3]` = 5, `[5]` нет длины 2. А `[1, 2, 3, 4, 5]`: пары длины 2: `[1,2]=3`, `[2,3]=5`, `[3,4]=7`, `[4,5]=9`. Только одна даёт 5. А ожидается 2... Подвох!

Тест `[1, 2, 3, 4, 5], 2, 5` действительно даёт 2: суммы `[2,3]=5` и `[1,4]=5`... нет, 1+4 не соседи. Ошибка в тесте. Давайте исправим:

Тест `[1, 2, 3, 4, 5], 2, 5`:
- [1,2] = 3
- [2,3] = 5 ✅
- [3,4] = 7
- [4,5] = 9
→ count = 1, а не 2.

Исправленный тест: `[1, 3, 2, 4, 5], 2, 5`:
- [1,3] = 4
- [3,2] = 5 ✅
- [2,4] = 6
- [4,5] = 9
→ count = 1

Давайте другой пример: `[2, 3, 5, 1, 4], 2, 5`:
- [2,3] = 5 ✅
- [3,5] = 8
- [5,1] = 6
- [1,4] = 5 ✅
→ count = 2 ✅

**Сложность:** O(n) по времени, O(1) по памяти.
