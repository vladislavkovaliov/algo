# Task 19: FindDuplicateNumber

## Паттерн: Комбинация (hash set)

**Зелёные флаги:** дубликат, n+1 чисел от 1 до n

## Условие

Дан массив `nums`, содержащий n + 1 целых чисел, каждое в диапазоне [1, n]. В массиве есть только один повторяющийся элемент. Найди его.

## Решение

```typescript
export function findDuplicate(nums: number[]): number {
    const seen = new Set<number>();
    for (const num of nums) {
        if (seen.has(num)) return num;
        seen.add(num);
    }
    return -1;
}
```

## Разбор

**Идея:** Используем Set для отслеживания встреченных чисел. Как только встречаем число, которое уже есть в Set — это дубликат.

**Пошагово на примере `[1, 3, 4, 2, 2]`:**

| Шаг | num | В seen? | Действие | seen |
|-----|-----|---------|----------|------|
| 1 | 1 | нет | add(1) | {1} |
| 2 | 3 | нет | add(3) | {1, 3} |
| 3 | 4 | нет | add(4) | {1, 3, 4} |
| 4 | 2 | нет | add(2) | {1, 3, 4, 2} |
| 5 | 2 | **да** | **return 2** | |

Ответ: `2`.

**Сложность:** O(n) по времени, O(n) по памяти.
