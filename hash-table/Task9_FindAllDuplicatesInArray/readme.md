# Task 9: FindAllDuplicatesInArray

## Паттерн: Выбор ключа

**Зелёные флаги:** дубликаты, набор чисел 1..n, Set

## Условие

Дан массив целых чисел `nums` длиной n, где nums[i] ∈ [1, n]. Каждое число появляется один или два раза. Верни массив всех чисел, которые встречаются дважды.

## Решение

```typescript
export function findDuplicates(nums: number[]): number[] {
    const seen = new Set<number>();
    const result: number[] = [];
    for (const num of nums) {
        if (seen.has(num)) result.push(num);
        else seen.add(num);
    }
    return result;
}
```

## Разбор

**Идея:** Проходим по массиву. Если число уже встречалось — это дубликат, добавляем в результат. Иначе запоминаем.

**Пошагово на примере `[4, 3, 2, 7, 8, 2, 3, 1]`:**

| Шаг | num | В seen? | Действие | seen | result |
|-----|-----|---------|----------|------|--------|
| 1 | 4 | нет | seen.add(4) | {4} | [] |
| 2 | 3 | нет | seen.add(3) | {4, 3} | [] |
| 3 | 2 | нет | seen.add(2) | {4, 3, 2} | [] |
| 4 | 7 | нет | seen.add(7) | {4, 3, 2, 7} | [] |
| 5 | 8 | нет | seen.add(8) | {4, 3, 2, 7, 8} | [] |
| 6 | 2 | **да** | result.push(2) | — | [2] |
| 7 | 3 | **да** | result.push(3) | — | [2, 3] |
| 8 | 1 | нет | seen.add(1) | {4, 3, 2, 7, 8, 1} | [2, 3] |

Ответ: `[2, 3]`.

**Сложность:** O(n) по времени, O(n) по памяти.
