# Task 1: ContainsDuplicate

## Паттерн: Техника подсчёта

**Зелёные флаги:** дубликат, проверить наличие, Set

## Условие

Дан массив целых чисел `nums`. Верни `true`, если какое-либо значение встречается в массиве хотя бы дважды, и `false`, если все элементы уникальны.

## Решение

```typescript
export function containsDuplicate(nums: number[]): boolean {
    const seen = new Set<number>();
    for (const num of nums) {
        if (seen.has(num)) return true;
        seen.add(num);
    }
    return false;
}
```

## Разбор

**Идея:** Используем `Set` для отслеживания уже встреченных чисел. Если число уже есть в наборе — нашли дубликат.

**Пошагово на примере `[1, 2, 3, 1]`:**

| Шаг | num | seen (до) | Дубликат? | seen (после) |
|-----|-----|-----------|-----------|--------------|
| 1 | 1 | {} | нет | {1} |
| 2 | 2 | {1} | нет | {1, 2} |
| 3 | 3 | {1, 2} | нет | {1, 2, 3} |
| 4 | 1 | {1, 2, 3} | **да** → return true |

Ответ: `true`.

**Сложность:** O(n) по времени, O(n) по памяти.
