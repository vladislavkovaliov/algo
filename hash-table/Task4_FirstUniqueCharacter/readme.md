# Task 4: FirstUniqueCharacter

## Паттерн: Техника подсчёта

**Зелёные флаги:** первый неповторяющийся символ, частота, второй проход

## Условие

Дана строка `s`. Найди первый неповторяющийся символ и верни его индекс. Если такого нет — верни `-1`.

## Решение

```typescript
export function firstUniqChar(s: string): number {
    const count = new Map<string, number>();
    for (const ch of s) {
        count.set(ch, (count.get(ch) || 0) + 1);
    }
    for (let i = 0; i < s.length; i++) {
        if (count.get(s[i]) === 1) return i;
    }
    return -1;
}
```

## Разбор

**Идея:** Два прохода по строке. Первый — считаем частоты всех символов. Второй — ищем первый символ с частотой 1.

**Пошагово на примере `"loveleetcode"`:**

Первый проход — считаем частоты:

| Символ | l | o | v | e | t | c | d |
|--------|---|---|---|---|---|---|---|
| Частота | 2 | 2 | 1 | 4 | 1 | 1 | 1 |

Второй проход — ищем первую единицу:

| i | Символ | Частота | Результат |
|---|--------|---------|-----------|
| 0 | l | 2 | нет |
| 1 | o | 2 | нет |
| 2 | v | **1** | **return 2** |

Ответ: `2`.

**Сложность:** O(n) по времени, O(k) по памяти.
