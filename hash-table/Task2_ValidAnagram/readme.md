# Task 2: ValidAnagram

## Паттерн: Техника подсчёта

**Зелёные флаги:** анаграмма, сравнить частоты символов

## Условие

Даны две строки `s` и `t`. Верни `true`, если `t` является анаграммой `s`, и `false` в противном случае.

## Решение

```typescript
export function isAnagram(s: string, t: string): boolean {
    if (s.length !== t.length) return false;

    const count = new Map<string, number>();
    for (const ch of s) {
        count.set(ch, (count.get(ch) || 0) + 1);
    }
    for (const ch of t) {
        const val = count.get(ch);
        if (!val) return false;
        count.set(ch, val - 1);
    }
    return true;
}
```

## Разбор

**Идея:** Сначала считаем частоту каждого символа в `s`. Затем проходим по `t` и уменьшаем счётчик. Если символ отсутствует или счётчик ушёл в ноль — это не анаграмма.

**Пошагово на примере `s = "anagram"`, `t = "nagaram"`:**

Сначала считаем `s`:

| Символ | a | n | g | r | m |
|--------|---|---|---|---|---|
| Частота | 3 | 1 | 1 | 1 | 1 |

Проходим `t`:

| Шаг | ch | count.get(ch) | Действие |
|-----|----|---------------|----------|
| 1 | n | 1 | → 0 |
| 2 | a | 3 | → 2 |
| 3 | g | 1 | → 0 |
| 4 | a | 2 | → 1 |
| 5 | r | 1 | → 0 |
| 6 | a | 1 | → 0 |
| 7 | m | 1 | → 0 |

Все счётчики в 0 → `true`.

**Сложность:** O(n) по времени, O(k) по памяти, где k — размер алфавита.
