# Task 6: MajorityElement

## Паттерн: Техника подсчёта

**Зелёные флаги:** чаще n/2, частота, ранний выход

## Условие

Дан массив `nums` размера n. Верни элемент, который встречается чаще n/2 раз. Гарантируется, что такой элемент всегда существует.

## Решение

```typescript
export function majorityElement(nums: number[]): number {
    const count = new Map<number, number>();
    const threshold = Math.floor(nums.length / 2);
    for (const num of nums) {
        const c = (count.get(num) || 0) + 1;
        if (c > threshold) return num;
        count.set(num, c);
    }
    return -1;
}
```

## Разбор

**Идея:** Считаем частоту каждого числа. Как только какое-то число превысило порог n/2 — сразу возвращаем его.

**Пошагово на примере `[2, 2, 1, 1, 1, 2, 2]`:**

Порог = Math.floor(7 / 2) = 3.

| Шаг | num | Счётчик | > 3? |
|-----|-----|---------|------|
| 1 | 2 | {2: 1} | нет |
| 2 | 2 | {2: 2} | нет |
| 3 | 1 | {2: 2, 1: 1} | нет |
| 4 | 1 | {2: 2, 1: 2} | нет |
| 5 | 1 | {2: 2, 1: 3} | нет |
| 6 | 2 | {2: 3, 1: 3} | нет |
| 7 | 2 | {2: **4**, 1: 3} | **да** → return 2 |

Ответ: `2`.

**Сложность:** O(n) по времени, O(n) по памяти.
