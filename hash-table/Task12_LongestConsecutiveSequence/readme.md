# Task 12: LongestConsecutiveSequence

## Паттерн: Выбор ключа

**Зелёные флаги:** последовательность, O(n), Set для lookup соседей

## Условие

Дан неотсортированный массив целых чисел `nums`. Верни длину самой длинной последовательной последовательности элементов. Алгоритм должен работать за O(n).

## Решение

```typescript
export function longestConsecutive(nums: number[]): number {
    const set = new Set(nums);
    let maxLen = 0;
    for (const num of set) {
        if (!set.has(num - 1)) {
            let len = 1;
            while (set.has(num + len)) len++;
            maxLen = Math.max(maxLen, len);
        }
    }
    return maxLen;
}
```

## Разбор

**Идея:** Помещаем все числа в Set. Проходим по Set и начинаем последовательность только если `num - 1` отсутствует (это начало последовательности). Затем расширяемся вправо. Это гарантирует O(n), так как каждый элемент проверяется не более 2 раз.

**Пошагово на примере `[100, 4, 200, 1, 3, 2]`:**

Set = {100, 4, 200, 1, 3, 2}.

| num | num-1 есть? | Длина | maxLen |
|-----|------------|-------|--------|
| 100 | 99 — нет | 1 | 1 |
| 4 | 3 — есть → пропускаем | — | 1 |
| 200 | 199 — нет | 1 | 1 |
| 1 | 0 — **нет** (начало!) | 1→2(1+1=2)→3(1+2=3)→4(1+3=4) | **4** |
| 3 | 2 — есть → пропускаем | — | 4 |
| 2 | 1 — есть → пропускаем | — | 4 |

Ответ: `4` (последовательность [1, 2, 3, 4]).

**Сложность:** O(n) по времени, O(n) по памяти.
