# Task 10: HappyNumber

## Паттерн: Выбор ключа

**Зелёные флаги:** цикл, set для отслеживания состояний, детекция цикла

## Условие

Счастливое число — это число, которое после замены суммой квадратов его цифр в итоге становится 1. Если процесс входит в бесконечный цикл (никогда не достигает 1), число не является счастливым. Верни `true`, если n — счастливое число.

## Решение

```typescript
function sumSquares(n: number): number {
    let sum = 0;
    while (n > 0) {
        const d = n % 10;
        sum += d * d;
        n = Math.floor(n / 10);
    }
    return sum;
}

export function isHappy(n: number): boolean {
    const seen = new Set<number>();
    while (n !== 1 && !seen.has(n)) {
        seen.add(n);
        n = sumSquares(n);
    }
    return n === 1;
}
```

## Разбор

**Идея:** Вычисляем сумму квадратов цифр. Если получаем 1 — число счастливое. Если видим число, которое уже было — мы в цикле, значит не счастливое.

**Пошагово на примере `n = 19`:**

| Шаг | n | Сумма квадратов цифр | В seen? |
|-----|---|----------------------|---------|
| 1 | 19 | 1² + 9² = 82 | нет → add(19) |
| 2 | 82 | 8² + 2² = 68 | нет → add(82) |
| 3 | 68 | 6² + 8² = 100 | нет → add(68) |
| 4 | 100 | 1² + 0² + 0² = 1 | нет → add(100) |
| 5 | **1** | — | **return true** |

**Пошагово на примере `n = 2`:**

| Шаг | n | Сумма квадратов | В seen? |
|-----|---|-----------------|---------|
| 1 | 2 | 4 | нет → add(2) |
| 2 | 4 | 16 | нет → add(4) |
| 3 | 16 | 37 | нет → add(16) |
| 4 | 37 | 58 | нет → add(37) |
| 5 | 58 | 89 | нет → add(58) |
| 6 | 89 | 145 | нет → add(89) |
| 7 | 145 | 42 | нет → add(145) |
| 8 | 42 | 20 | нет → add(42) |
| 9 | 20 | 4 | **да** (цикл!) → return false |

**Сложность:** O(log n) по времени (в худшем), O(log n) по памяти.
