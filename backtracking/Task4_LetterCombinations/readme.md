# Task4: LetterCombinations

## Паттерн: Брутфорс (перебор по дереву вариантов)

**Зелёные флаги:** каждая цифра раскрывается в несколько букв, нужно перебрать все «узлы» дерева

## Условие

Дана строка `digits` (цифры 2–9). Верни все буквенные комбинации, которые можно собрать по правилам телефонной клавиатуры: `2→abc, 3→def, 4→ghi, 5→jkl, 6→mno, 7→pqrs, 8→tuv, 9→wxyz`.

---

**Постановка:** для каждой цифры на i-й позиции перебираем все её буквы и добавляем по одной. Глубина рекурсии = длина строки `digits`; когда прошли все цифры — комбинация готова.

**Почему это Брутфорс, а не Бектрекинг?** Для каждой цифры ВСЕ её буквы всегда допустимы — ограничений нет, отсекать нечего. Фреймворк §9: «все комбинации/перестановки без ограничений → **Брутфорс**». Это и есть обход дерева всех вариантов.

**Почему это комбинаторика?** Количество комбинаций = произведению количества букв по каждой цифре (для 23 это 3×3=9). Задача «вернуть все варианты».

**Внимание на пустой вход:** если `digits` пустая, комбинаций нет → возвращаем `[]`.

**Пошагово на примере digits = "23":**

| Уровень | Действие | path |
|---|---|---|
| 0 | берём буквы '2': a, b, c | '' → 'a' |
| 1 | для 'a' берём буквы '3': d, e, f | 'ad' ✅ |
| ... | ... | 'ae', 'af' ✅ |
| 0 | возврат к '3' | 'b' |
| 1 | буквы '3': | 'bd','be','bf' ✅ |
| 0 | возврат к '3' | 'c' |
| 1 | буквы '3': | 'cd','ce','cf' ✅ |

Ответ: `["ad","ae","af","bd","be","bf","cd","ce","cf"]`

## Решение

```typescript
const MAP: Record<string, string> = {
    '2': 'abc', '3': 'def', '4': 'ghi', '5': 'jkl',
    '6': 'mno', '7': 'pqrs', '8': 'tuv', '9': 'wxyz',
};

export function letterCombinations(digits: string): string[] {
    if (digits.length === 0) return [];
    const result: string[] = [];

    function backtrack(index: number, path: string): void {
        if (index === digits.length) {
            result.push(path);
            return;
        }
        for (const ch of MAP[digits[index]]) {
            backtrack(index + 1, path + ch);
        }
    }

    backtrack(0, '');
    return result;
}
```

## Разбор

**Идея:** рекурсивно раскрываем каждую цифру во все её буквы. Здесь не нужно `pop()` — используем неизменяемую строку в качестве `path`.

**Сложность:** O(4ⁿ · n), где 4 — максимум букв на цифру (7 и 9 имеют по 4), n — длина digits. Память O(n) для стека рекурсии.
