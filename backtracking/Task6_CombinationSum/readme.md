# Task6: CombinationSum

## Паттерн: Бектрекинг (отсечение по сумме)

**Зелёные флаги:** можно повторно использовать число, сумма равна target, все комбинации

## Условие

Дан массив уникальных чисел `candidates` и цель `target`. Верни все комбинации чисел (с повторениями), дающие в сумме `target`.

---

**Постановка:** перебираем числа с помощью индекса `start`, но с одним важным отличием: одно и то же число можно брать повторно, поэтому рекурсия вызывается с **тем же** индексом `i` (а не `i+1`). Сумма накапливается в аргументе `remaining` — это упрощает проверку условия конца.

**Что если remaining < 0?** Ветка невалидна, отсекаем её (pruning).

**Почему порядок элементов в комбинации неубывающий?** Индекс `start` не даст вернуться к меньшим индексам, поэтому `[2,3]` и `[3,2]` не будут считаться разными — дублей нет.

**Пошагово на примере candidates = [2, 3, 5], target = 8:**

| path | remaining | Действие |
|---|---|---|
| [] | 8 | берём 2 → [2], 6 |
| [2] | 6 | берём 2 → [2,2], 4 |
| [2,2] | 4 | берём 2 → [2,2,2], 2 |
| [2,2,2] | 2 | берём 2 → remaining=0 ✅ |
| ... | ... | [2,3,3] ✅, [3,5] ✅ |

Ответ: `[[2,2,2,2],[2,3,3],[3,5]]`

## Решение

```typescript
export function combinationSum(candidates: number[], target: number): number[][] {
    const result: number[][] = [];

    function backtrack(start: number, remaining: number, path: number[]): void {
        if (remaining === 0) {
            result.push([...path]);
            return;
        }
        for (let i = start; i < candidates.length; i++) {
            if (candidates[i] > remaining) continue;
            path.push(candidates[i]);
            backtrack(i, remaining - candidates[i], path);
            path.pop();
        }
    }

    backtrack(0, target, []);
    return result;
}
```

## Разбор

**Идея:** классическая задача «комбинации с повторениями». Важный приём — вызов `backtrack(i, ...)` вместо `backtrack(i + 1, ...)` позволяет использовать число многократно.

**Сложность:** O(target/min(candidates)) веток в худшем случае, память O(target). На практике число комбинаций сильно ограничено отсечением по сумме.
