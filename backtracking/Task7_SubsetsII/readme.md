# Task7: SubsetsII

## Паттерн: Бектрекинг (дубликаты через сортировку + пропуск)

**Зелёные флаги:** массив может содержать дубликаты, без дублирующихся подмножеств

## Условие

Дан массив `nums` с возможными дубликатами. Верни все уникальные подмножества.

---

**Постановка:** базовый алгоритм из Task1 дал бы дубли, потому что элементы `2` в `[1,2,2]` неотличимы друг от друга. Решение: сначала отсортировать массив, а затем в цикле пропускать одинаковые элементы на одном уровне рекурсии.

**Ключевое правило:** `if (i > start && nums[i] === nums[i-1]) continue;` — если на текущем уровне уже начали с `nums[i]`, то такой же элемент повторно обрабатывать не нужно.

**Почему сортировка обязательна?** Чтобы одинаковые элементы стояли рядом — только тогда проверка `nums[i] === nums[i-1]` корректна.

**Пошагово на примере nums = [1, 2, 2]:**

| path | Действие |
|---|---|
| [] | сохраняем |
| [1] | сохраняем, добавляем 2 |
| [1,2] | сохраняем, добавляем 2 |
| [1,2,2] | сохраняем ✅ |
| [1,2] | откат, берём второй 2 — пропускаем (дубль) |
| [2] | сохраняем, добавляем 2 |
| [2,2] | сохраняем ✅ |

Ответ: `[[],[1],[1,2],[1,2,2],[2],[2,2]]`

## Решение

```typescript
export function subsetsWithDup(nums: number[]): number[][] {
    nums.sort((a, b) => a - b);
    const result: number[][] = [];

    function backtrack(start: number, path: number[]): void {
        result.push([...path]);
        for (let i = start; i < nums.length; i++) {
            if (i > start && nums[i] === nums[i - 1]) continue;
            path.push(nums[i]);
            backtrack(i + 1, path);
            path.pop();
        }
    }

    backtrack(0, []);
    return result;
}
```

## Разбор

**Идея:** паттерн «сортировка + пропуск одинаковых на одном уровне» — стандартный приём для всех задач с дубликатами (SubsetsII, PermutationsII, CombinationSumII).

**Сложность:** O(n·2ⁿ) по времени в худшем случае, O(n) по памяти для стека рекурсии.
