# Task13: BeautifulArrangement

## Паттерн: Бектрекинг (перестановки с условием на позицию)

**Зелёные флаги:** перестановки от 1 до n + условие делимости, количество способов

## Условие

Дано `n`. Посчитай количество перестановок чисел `1..n`, где на каждой позиции `i` (1-indexed) число `a[i]` делится на позицию ИЛИ позиция делится на число.

---

**Постановка:** это перестановки с условием на месте позиции. Держим позицию `pos` как параметр рекурсии, перебираем числа от 1 до n, и берём те, которые можно поставить на позицию `pos`. Проверка условия — это отсечение веток (pruning), ровно как в других задачах.

**Чем отличается от Task2?** Базовый случай тот же, но на каждом уровне мы фильтруем кандидатов по условию делимости II вместо построения перестановки без условий.

**Пошагово на примере n = 3:**

| Позиция | Возможные числа |
|---|---|
| 1 | 1 (1%1=0), 2 (2%1=0), 3 (3%1=0) |
| 2 | 1 (2%1=0), 2 (2%2=0), 3 (3%2=0) |
| 3 | 1 (3%1=0), 3 (3%3=0) |

Подходящие перестановки: [1,2,3],[2,1,3],[3,1,2] → 3 штуки ✅

## Решение

```typescript
export function countArrangement(n: number): number {
    let count = 0;
    const used: boolean[] = new Array(n + 1).fill(false);

    function backtrack(pos: number): void {
        if (pos > n) {
            count++;
            return;
        }
        for (let i = 1; i <= n; i++) {
            if (used[i]) continue;
            if (i % pos !== 0 && pos % i !== 0) continue;
            used[i] = true;
            backtrack(pos + 1);
            used[i] = false;
        }
    }

    backtrack(1);
    return count;
}
```

## Разбор

**Идея:** перебираем перестановки, но отсекаем все ветки, где текущее число нельзя поставить на текущую позицию. Это сильное сокращение — перестановок 20! для n=20, а тут большинство веток отсекаются почти сразу.

**Совет:** такой перебор работает, потому что отсечение сильное; на больших n надо было бы думать о мемоизации (это уже ДП).

**Сложность:** O(n·n!) в худшем случае, но на практике сильно меньше; память O(n).
