# Task16: SolveSudoku

## Паттерн: Бектрекинг (перебор клеток с проверкой валидности)

**Зелёные флаги:** судоку, заполнение по правилам, единственное решение

## Условие

Заполни доску судоку 9×9. Пустые клетки — `'.'`. Каждую строку, столбец и блок 3×3 должны занимать цифры 1–9 без повторов.

---

**Постановка:** бектрекинг со стратегией «первая пустая клетка». В рекурсии ищем в доске первый `'.'`, для него пробуем цифры 1–9. Если цифра валидна в клетке — ставим и рекурсивно решаем доску дальше; если доску решить не удалось — убираем цифру и пробуем следующую.

**Ключевая находка:** эта стратегия работает, потому что судоку имеет единственное полное решение. Нет надобности «выбирать самую обещающую клетку» — любая стратегия приведёт к ответу.

**Отсечение:** функция `isValid(r, c, digit)` проверяет строку, столбец и блок 3×3 за O(9). Её «continue» — это и есть pruning.

**Почему return из рекурсии boolean?** Нам нужно ТОЛЬКО одно решение (или доказательство невозможности). Возвращая `true` при первом найденном решении, мы отсекаем все остальные ветки.

## Решение

```typescript
export function solveSudoku(board: string[][]): string[][] {
    function isValid(row: number, col: number, digit: string): boolean {
        for (let i = 0; i < 9; i++) {
            if (board[row][i] === digit) return false;
            if (board[i][col] === digit) return false;
            const br = Math.floor(row / 3) * 3 + Math.floor(i / 3);
            const bc = Math.floor(col / 3) * 3 + (i % 3);
            if (board[br][bc] === digit) return false;
        }
        return true;
    }

    function solve(): boolean {
        for (let row = 0; row < 9; row++) {
            for (let col = 0; col < 9; col++) {
                if (board[row][col] !== '.') continue;
                for (let d = 1; d <= 9; d++) {
                    const digit = String(d);
                    if (!isValid(row, col, digit)) continue;
                    board[row][col] = digit;
                    if (solve()) return true;
                    board[row][col] = '.';
                }
                return false;
            }
        }
        return true;
    }

    solve();
    return board;
}
```

## Разбор

**Идея:** идея «первой пустой клетки» + попытка всех вариантов + откат при неудаче. Это классический constraint-satisfaction бектрекинг.

**Сложность:** в худшем случае экспоненциальная, на практике — быстрая благодаря жёсткому отсечению по правилам судоку (81 клетка, ограниченные варианты).
