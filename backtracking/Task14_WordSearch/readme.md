# Task14: WordSearch

## Паттерн: Бектрекинг (перебор по сетке с visited)

**Зелёные флаги:** слово на сетке, клетка не может использоваться дважды → visited/mut

## Условие

Дан `board` (m × n) из букв и слово `word`. Определи, существует ли слово в сетке: двигаемся вверх/вниз/влево/вправо, каждая клетка — один раз.

---

**Постановка:** перебираем все стартовые клетки; из каждой стартуем DFS. На каждом шаге, если буква не совпадает с нужной — отсекаем ветку. Чтобы не ходить по одной клетке дважды, временно помечаем её как занятую (`board[r][c] = '#'`) и после возврата восстанавливаем. Это и есть бектрекинг по сетке.

**Что важно:** поиск DFS здесь ищет **один** конкретный путь, а не собирает все, поэтому возвращаем `boolean` при нахождении.

**Почему не visited-массив?** Можно и массив, но мутация board — изящнее и экономнее (альтернативный visited эквивалентен).

**Пошагово на примере word = "ABCB", board = [["A","B","C","E"],["S","F","C","S"],["A","D","E","E"]]:**

| Шаг | Клетка | Состояние |
|---|---|---|
| 1 | (0,0)='A' | совпало, идём дальше |
| 2 | (0,1)='B' | совпало |
| 3 | (0,2)='C' | совпало |
| 4 | ищем 'B' вокруг (0,2) | нет (C уже пройдена, E/S) → backtrack → false |

Ответ: false ✅

## Решение

```typescript
export function exist(board: string[][], word: string): boolean {
    const m = board.length;
    const n = board[0].length;

    function dfs(r: number, c: number, index: number): boolean {
        if (index === word.length) return true;
        if (r < 0 || r >= m || c < 0 || c >= n || board[r][c] !== word[index]) return false;

        const tmp = board[r][c];
        board[r][c] = '#';
        const found = dfs(r + 1, c, index + 1)
            || dfs(r - 1, c, index + 1)
            || dfs(r, c + 1, index + 1)
            || dfs(r, c - 1, index + 1);
        board[r][c] = tmp;
        return found;
    }

    for (let r = 0; r < m; r++) {
        for (let c = 0; c < n; c++) {
            if (dfs(r, c, 0)) return true;
        }
    }
    return false;
}
```

## Разбор

**Идея:** DFS с отсечением по несовпадению символа и с временной пометкой занятой клетки. `||` для четырёх направлений = классический бектрекинг.

**Сложность:** O(m·n·3^L) по времени в худшем случае (L — длина слова), O(L) для стека рекурсии.
