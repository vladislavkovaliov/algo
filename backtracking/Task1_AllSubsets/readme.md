# Task1: AllSubsets

## Паттерн: Брутфорс (все комбинации без ограничений)

**Зелёные флаги:** все подмножества, power set, вернуть все варианты, 2ⁿ результатов, нет ограничений на отсечение

## Условие

Дан массив уникальных чисел `nums`. Верни **все** возможные подмножества (включая пустое).

---

**Постановка:** на каждом шаге для элемента решаем «брать или не брать». Удобно реализовать рекурсией с индексом `start`: в каждом состоянии текущий `path` и есть подмножество — его сохраняем, затем пробуем добавить каждый следующий элемент и углубляемся.

**Почему это Брутфорс, а не Бектрекинг?** Фреймворк §9: «Всё остальное (все комбинации/перестановки без ограничений) → **Брутфорс**». Здесь нет никаких ограничений, которые позволили бы отсечь ветку заранее — мы обязаны выписать все 2ⁿ вариантов. Отсекать нечего, поэтому это чистый перебор.

**Почему это комбинаторика?** Всего подмножеств 2ⁿ — базовый перебор без ограничений.

**Пошагово на примере nums = [1, 2, 3]:**

| Состояние path | Что делаем | Результат |
|---|---|---|
| [] | сохраняем, добавляем 1 | [] |
| [1] | сохраняем, добавляем 2 | [1] |
| [1,2] | сохраняем, добавляем 3 | [1,2] |
| [1,2,3] | сохраняем, откат | [1,2,3] |
| [1,3] | сохраняем, откат | [1,3] |
| [2] | сохраняем, добавляем 3 | [2] |
| [2,3] | сохраняем | [2,3] |
| [3] | сохраняем | [3] |

Ответ: `[[], [1], [1,2], [1,2,3], [1,3], [2], [2,3], [3]]`

## Решение

```typescript
export function subsets(nums: number[]): number[][] {
    const result: number[][] = [];

    function backtrack(start: number, path: number[]): void {
        result.push([...path]);
        for (let i = start; i < nums.length; i++) {
            path.push(nums[i]);
            backtrack(i + 1, path);
            path.pop();
        }
    }

    backtrack(0, []);
    return result;
}
```

## Разбор

**Идея:** классический перебор всех подмножеств. Каждый вызов `backtrack` сохраняет текущее состояние `path`, потом перебирает следующие элементы (только те, что идут после `start`, — это гарантирует отсутствие дублей и порядок).

**Почему `path.pop()` нужен?** Без отката элементы будут накапливаться — после обработки ветки обязаны убрать последний добавленный элемент, чтобы вернуться в предыдущее состояние.

**Сложность:** O(2ⁿ) вариантов × O(n) на копирование = O(n·2ⁿ) по времени, O(n) по памяти для стека рекурсии.
