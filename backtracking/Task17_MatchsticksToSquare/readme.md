# Task17: MatchsticksToSquare

## Паттерн: Бектрекинг (разбиение на 4 равные части)

**Зелёные флаги:** квадрат из спичек, все спички использовать, четыре равные стороны

## Условие

Дан массив длин спичек. Можно ли, используя **все** спички, сложить квадрат?

---

**Постановка:** математически задача — «можно ли разбить массив на 4 подмножества с равной суммой». Сумма всех спичек должна делиться на 4, и каждая сторона равна `total/4`. Далее — бектрекинг по распределению спичек по 4 «ведрам»-сторонам.

**Почему сортировка по убыванию?** Большие спички ставятся первыми — это резко сокращает дерево (неудачные большие вставки отсекаются раньше).

**Отсечения:**
- сумма не делится на 4 → false;
- самая длинная спичка больше стороны → false;
- пропуск одинаковых сторон (`sides[s] === sides[s-1]`), чтобы не пробовать заведомо эквивалентные ветки.

**Пошагово на примере [1, 1, 2, 2, 2]:** сумма 8, сторона 2. Сортируем [2,2,2,1,1]. Распределяем: сторона1={2}, сторона2={2}, сторона3={2}, сторона4={1,1} → true ✅

## Решение

```typescript
export function makesquare(matchsticks: number[]): boolean {
    const total = matchsticks.reduce((a, b) => a + b, 0);
    if (total % 4 !== 0) return false;
    const side = total / 4;
    matchsticks.sort((a, b) => b - a);
    if (matchsticks[0] > side) return false;

    const sides = [0, 0, 0, 0];

    function backtrack(i: number): boolean {
        if (i === matchsticks.length) {
            return sides[0] === side && sides[1] === side && sides[2] === side && sides[3] === side;
        }
        for (let s = 0; s < 4; s++) {
            if (sides[s] + matchsticks[i] > side) continue;
            if (s > 0 && sides[s] === sides[s - 1]) continue;
            sides[s] += matchsticks[i];
            if (backtrack(i + 1)) return true;
            sides[s] -= matchsticks[i];
        }
        return false;
    }

    return backtrack(0);
}
```

## Разбор

**Идея:** распределяем спички по 4 сторонам (вёдрам). Возвращаем `true` при первом успехе — поэтому функция возвращает boolean.

**Сложность:** экспоненциальная в худшем случае, но сортировка + пропуск одинаковых сторон сильно ускоряют.
