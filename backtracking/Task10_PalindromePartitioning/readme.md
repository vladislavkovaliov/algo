# Task10: PalindromePartitioning

## Паттерн: Бектрекинг (разбиение на подстроки)

**Зелёные флаги:** разбиение строки, все способы, подстроки-палиндромы

## Условие

Дана строка `s`. Верни все возможные разбиения `s` на палиндромные подстроки.

---

**Постановка:** рекурсивно перебираем конец первой подстроки `i` от `start` до конца строки. Подстрока `s[start..i]`, если она палиндром — кладём в path, рекурсивно продолжаем с `i + 1`. Это ровно такой же каркас, как в CombinationSum, но «набор чисел» заменён на «подстроки».

**Что отсекаем?** Непалиндромные подстроки — ветка продолжения неполна, если первую часть нельзя сделать палиндромом.

**Пошагово на примере s = "aab":**

| start | Подстрока | Палиндром? | path |
|---|---|---|---|
| 0 | "a" | да | [a] |
| 1 | "a" | да | [a, a] |
| 2 | "b" | да | [a,a,b] ✅ |
| 0 | "aa" | да | [aa] |
| 2 | "b" | да | [aa,b] ✅ |
| 0 | "aab" | нет | отсекаем |

Ответ: `[["a","a","b"],["aa","b"]]`

## Решение

```typescript
export function partition(s: string): string[][] {
    const result: string[][] = [];

    function isPalindrome(str: string): boolean {
        let l = 0, r = str.length - 1;
        while (l < r) {
            if (str[l] !== str[r]) return false;
            l++;
            r--;
        }
        return true;
    }

    function backtrack(start: number, path: string[]): void {
        if (start === s.length) {
            result.push([...path]);
            return;
        }
        for (let i = start; i < s.length; i++) {
            const sub = s.slice(start, i + 1);
            if (!isPalindrome(sub)) continue;
            path.push(sub);
            backtrack(i + 1, path);
            path.pop();
        }
    }

    backtrack(0, []);
    return result;
}
```

## Разбор

**Идея:** перебор всех подстрок с отсечением непалиндромных. Вместо накопления числовой суммы проверяем свойство подстроки — это тот же паттерн бектрекинга, другое условие валидности.

**Сложность:** O(n·2ⁿ) по времени в худшем случае, O(n) по памяти для стека рекурсии.
