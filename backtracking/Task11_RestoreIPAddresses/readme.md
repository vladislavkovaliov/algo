# Task11: RestoreIPAddresses

## Паттерн: Бектрекинг (сегменты строки с жёсткими отсечениями)

**Зелёные флаги:** вставить точки, сегмент от 0 до 255, без ведущих нулей, все варианты

## Условие

Дана цифровая строка `s`. Верни все корректные IPv4-адреса, полученные вставкой трёх точек.

---

**Постановка:** строим IP из 4 сегментов. На каждом шаге берём следующий сегмент длиной 1, 2 или 3 символа (ибо сегмент ≤ 255). Отсечения:
1. `len > 1 && сегмент начинается с '0'` → невалидно (нет ведущих нулей).
2. `Number(сегмент) > 255` → невалидно.
3. Остановка: собрали 4 сегмента и использовали всю строку.

**Почему ограничение длины сегментов важно?** Это уменьшает ветвление: на каждом уровне максимум 3 варианта, а не вся оставшаяся строка.

**Пошагово на примере s = "25525511135":**

| Сегменты | Оставшееся | Действие |
|---|---|---|
| [] | "25525511135" | берём "255" |
| ["255"] | "25511135" | берём "255" |
| ["255","255"] | "11135" | берём "11" |
| ["255","255","11"] | "135" | берём "135" ✅ → 255.255.11.135 |
| ... | ... | 255.255.111.35 ✅ |

Ответ: `["255.255.11.135","255.255.111.35"]`

## Решение

```typescript
export function restoreIpAddresses(s: string): string[] {
    const result: string[] = [];

    function backtrack(start: number, parts: string[]): void {
        if (parts.length === 4) {
            if (start === s.length) result.push(parts.join('.'));
            return;
        }
        for (let len = 1; len <= 3; len++) {
            if (start + len > s.length) break;
            const segment = s.slice(start, start + len);
            if (segment.length > 1 && segment[0] === '0') continue;
            if (Number(segment) > 255) continue;
            parts.push(segment);
            backtrack(start + len, parts);
            parts.pop();
        }
    }

    backtrack(0, []);
    return result;
}
```

## Разбор

**Идея:** перебор сегментов фиксированной максимальной длины с проверкой валидности числа. Классический бектрекинг по индексу в строке.

**Сложность:** O(3⁴ · 1) ≈ O(1) по времени (ограниченное дерево: 3 варианта на 4 уровня), реально — перебираются только валидные части.
