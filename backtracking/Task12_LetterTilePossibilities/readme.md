# Task12: LetterTilePossibilities

## Паттерн: Бектрекинг (счётчик, а не список)

**Зелёные флаги:** количество последовательностей, ограничение по частоте букв, результат — число

## Условие

Дан набор букв `tiles`. Верни **количество** непустых последовательностей, которые можно из них составить (каждую букву используют сколько встретилось раз).

---

**Постановка:** отличие от предыдущих задач — **не нужно собирать сами сочетания**, только посчитать их. Можно перебирать без массива ответов: на каждом состоянии для каждого символа A–Z, если он ещё доступен, считаем текущую последовательность (+1) и углубляемся, уменьшив доступность буквы.

**Ключевой приём:** массив частот `count[26]` вместо списка букв. Символы одинаковых букв неотличимы, поэтому подсчёт идёт по наличию буквы, а не по позиции.

**Пошагово на примере tiles = "AAB":** частоты {A:2, B:1}

| Путь сокращений | Добавлено |
|---|---|
| начинаем с пустого (не считаем) | 0 |
| берём A (частота 1 из 2) | +1 |
| берём A (0 из 2) | +1, берём B | +1 |
| берём B | +1, берём A | +1 |
| ... | всего 8 |

Ответ: 8 (A, B, AA, AB, BA, AAB, ABA, BAA)

## Решение

```typescript
export function numTilePossibilities(tiles: string): number {
    const count = new Array(26).fill(0);
    for (const ch of tiles) count[ch.charCodeAt(0) - 65]++;

    let total = 0;
    function backtrack(): void {
        for (let i = 0; i < 26; i++) {
            if (count[i] === 0) continue;
            total++;
            count[i]--;
            backtrack();
            count[i]++;
        }
    }
    backtrack();
    return total;
}
```

## Разбор

**Идея:** подсчёт через частоты. Каждый вызов `backtrack` перебирает буквы, которые ещё можно добавить; `count[i]--` и `++` имитируют взятие/возврат плитки.

**Зачем вообще перебор, если можно считать?** Здесь подсчёт идёт по всем комбинациям разной длины — это чистая комбинаторика без формулы; перебор позволяет не выводить математически сложную формулу.

**Сложность:** O(число последовательностей · 26) по времени, O(26) по памяти.
