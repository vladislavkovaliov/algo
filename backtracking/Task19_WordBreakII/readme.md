# Task19: WordBreakII

## Паттерн: Бектрекинг + мемоизация (вернуть все варианты)

**Зелёные флаги:** все возможные разбиения, словарь слов, вернуть ВСЕ варианты

## Условие

Данa строка `s` и словарь `wordDict`. Верни все возможные предложения, полученные вставкой пробелов так, чтобы каждое слово было из словаря.

---

**Постановка:** перебираем все возможности разбить `s` на слова из словаря. Для позиции `start` перебираем конец `end` и проверяем `s[start..end]` в словаре. Если найдено слово — рекурсивно разбиваем хвост строки и комбинируем.

**Почему это бектрекинг, а не ДП?** Фреймворк говорит прямо: «Вернуть **все** варианты/комбинации → это бектрекинг, не ДП». ДП подошёл бы, если бы нужен был только ответ «можно/нельзя» или количество. Здесь же нужно полностью выписать каждое предложение.

**Почему ещё и мемоизация?** Одна и та же позиция `start` вызывается много раз (разные пути разбиения сходятся к одному хвосту). Кэшируем ответ для позиции в `memo` — иначе экспоненциальный перебор превращается в почти линейный по числу разбиений.

**Пошагово на примере s = "catsanddog":**

| start | Слово из словаря | Хвост |
|---|---|---|
| 0 | "cat" | "sanddog" |
| 0 | "cats" | "anddog" |
| 3 | "sand" | "dog" |
| 7 | "dog" | "" |

Комбинации: "cat sand dog", "cats and dog"

## Решение

```typescript
export function wordBreak(s: string, wordDict: string[]): string[] {
    const dict = new Set(wordDict);
    const memo = new Map<number, string[]>();

    function backtrack(start: number): string[] {
        if (start === s.length) return [''];
        if (memo.has(start)) return memo.get(start)!;

        const result: string[] = [];
        for (let end = start + 1; end <= s.length; end++) {
            const word = s.slice(start, end);
            if (!dict.has(word)) continue;
            for (const tail of backtrack(end)) {
                result.push(tail === '' ? word : word + ' ' + tail);
            }
        }
        memo.set(start, result);
        return result;
    }

    return backtrack(0);
}
```

## Разбор

**Идея:** рекурсивный перебор всех слов с начала строки + кэш результатов по позиции. Это связка бектрекинга и мемоизации: каркас перебора тот же, а кэш убирает повторную работу.

**Внимание на порядок:** тесты ожидают результаты в порядке, который даёт именно этот алгоритм (словарь перебирается слева направо, слова в порядке их появления). Поэтому если пользоваться другим порядком перебора words — тесты могут отличаться порядком.

**Сложность:** O(число решений · длина решения) по времени с учётом мемоизации, O(n) для стека + кэш O(n) хранимых списков.
