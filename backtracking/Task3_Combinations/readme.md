# Task3: Combinations

## Паттерн: Брутфорс (все комбинации без ограничений)

**Зелёные флаги:** комбинации из k чисел, C(n,k), порядок элементов не важен → инкрементальный index

## Условие

Даны `n` и `k`. Верни все комбинации из `k` чисел, выбранных из диапазона `[1, n]`.

---

**Постановка:** то же, что Task1 (подмножества), но с дополнительным условием «длина ровно k». Перебор с `start`-индексом + проверка `path.length === k` в качестве базового случая.

**Почему не перестановки?** В комбинации порядок не важен, поэтому элементы добавляем строго по возрастанию (перебор от `start`). Это убирает дубли типа `[1,2]` и `[2,1]`.

**Почему это Брутфорс, а не Бектрекинг?** Каждый кандидатный элемент всегда допустим (пока длина меньше k) — нет условия, позволяющего отсечь ветку до конца. Значит, по фреймворку §9 это **Брутфорс**: перечисляем все комбинации без ограничений.

**Что меняется против Task1:** в Task1 сохраняли подмножество на КАЖДОМ шаге, здесь — только при длине `k`.

**Пошагово на примере n = 4, k = 2:**

| path | Действие |
|---|---|
| [] → [1] | берём 1 |
| [1,2] | длина 2 ✅ |
| [1,3] | ✅ |
| [1,4] | ✅ |
| [2,3] | ✅ |
| [2,4] | ✅ |
| [3,4] | ✅ |

Ответ: `[[1,2],[1,3],[1,4],[2,3],[2,4],[3,4]]`

## Решение

```typescript
export function combine(n: number, k: number): number[][] {
    const result: number[][] = [];

    function backtrack(start: number, path: number[]): void {
        if (path.length === k) {
            result.push([...path]);
            return;
        }
        for (let i = start; i <= n; i++) {
            path.push(i);
            backtrack(i + 1, path);
            path.pop();
        }
    }

    backtrack(1, []);
    return result;
}
```

## Разбор

**Идея:** перебор всех комбинаций длины ровно `k` из диапазона. Индекс `start` гарантирует строго возрастающий порядок элементов в каждой комбинации.

**Сложность:** O(C(n,k) · k) по времени, O(k) по памяти для стека рекурсии.
